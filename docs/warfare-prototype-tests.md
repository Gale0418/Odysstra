# W06｜六大攻防系統的最小原型、平衡實驗與驗收

> **【原型測試提案】**這些不是已通過的測試、不是已實作的玩法，也不是首版強制要做的所有功能。前提：以 [06｜戰鬥與指揮](06-combat-and-command.md) 的百艦指揮方向為主，既有 [17｜32 項總驗收](17-prototype-test-matrix.md) 與 [18｜WD-01～05](18-weapons-defense-and-tech-doctrine.md) 均保留。本文新增的 WD-06～WD-21 為**待執行**的專題試驗。

## 1. 最小切片：先驗證 3×3 是否真的有趣

**最少要有的可替換能力：**
- 實彈／射線／導彈各一種；裝甲／護盾／點防各一種。
- 導彈為可追蹤的有限載具；實彈是無自推進彈體；射線不生成可被反導點防擊落的載具。
- 點防可優先打導彈、戰機／無人機／突擊蟲（可用同一種「小型高速接近目標」原型代替），空閒時才對艦艇輔助射擊。
- 每艦明確顯示裝甲、護盾、船體、彈藥／載具庫存、熱量／能源、點防有效攔截量。
- **不要求**一開始做 15 階武器、16 種導彈、數萬個地雷實體、神級模組或可程式化月球。

**資訊透明**：讓玩家看得出「沒有命中」「被點防擊落」「護盾吸收」「裝甲損壞」「船體受創」「導彈庫存耗盡」的區別。若一個船突然爆炸，UI 不可只顯示爆炸特效而沒有原因。

## 2. 三種科學的最小參數集（全部待測）

| 領域 | 候選戰鬥參數 | 最重要的可觀測失敗 |
|---|---|---|
| 材料 | 砲彈質量／初速、發射週期、彈量、裝甲有效承傷、結構損傷 | 彈道落空、裝甲承受不足、重甲無法追敵 |
| 能量 | 束功率、聚焦、指向速度、電容、反應爐持續功率、熱容量、護盾容量／恢復 | 過熱、盾還在但船體被穿透、功率分配陷阱 |
| 自律 | 可用導彈／無人機數、出擊／回收、攔截能力、補充時間、雷／崗哨存量 | 母艦完整但**沒有可射／可派的載具**、部署區被清空 |

**重要：**這些是「將來要有的參數類型」，不是目前遊戲已有這些欄位。

## 3. 軟性剋制而不是三個永久免疫

- **實彈 → 主要由裝甲承受**，但護盾可以在有代價下偏折、減速或過載；未定具體效果。
- **射線 → 主要由護盾處理**，護盾失效、被穿透或散熱不足時，裝甲／船體仍受傷。
- **導彈 → 主要受點防攔截**，未被攔的彈頭依其物理／場特性再和盾／甲互動。**不**因是導彈就自動穿甲。
- **點防 → 能攔小型載具、蟲群與戰機**；空閒能打大型艦但效率低；**不能可靠攔宏觀軌道炮彈、不能擊落已到達的射線本身**。
- 不設定「碰到剋星必輸」。專精深度、火控、距離、後勤、艦隊數量與撤退路徑都可以改變勝負。
- 若要測試百分比剋制，只能標【測試預設】，不得把某次聊天舉例的 1.5 倍、5% 或 80% 寫成正式平衡值。

## 4. P-001 可測戰鬥案例（在原戰鬥原型內加測）

| ID | 假設 | 測試設計 | 期待觀察；不是已通過 |
|---|---|---|---|
| WD-06 | PD 有事情做而非裝飾 | 同樣 PD 艦，一場敵軍射導彈、另一場只帶巨艦 | 第一場有效攔截；第二場自動轉為輔助對艦 |
| WD-07 | 反導擅長群體載具 | 將導彈、戰機與蟲群都標成「可攔截小型目標」 | 反導依實際威脅優先決策，不因目標叫「蟲」就停火 |
| WD-08 | PD 不取代裝甲 | 與相同量普通無自推進軌道炮彈交戰 | 砲彈主要進裝甲／護盾交互；反導不提供可靠防線 |
| WD-09 | 三防階段清楚 | 同時有導彈與射線的混合齊射 | 不把射線當飛彈擊落；顯示各自被哪層攔住 |
| WD-10 | 外圈雷區有戰術價值 | 一次使用近防，一次加預布雷區 | 外圈能提早減少來襲數；須付出佈雷時間／物資 |
| WD-11 | 雷區不是免費萬能牆 | 敵軍掃雷／繞路／誘餌；同一場加遠程崗哨 | 陣地可被反制、會耗彈與退化，玩家看得懂 |
| WD-12 | 自律續航有獨特弱點 | 相同母艦兩場連戰，中間不能補載具 | 第二戰有效攻勢顯著下降，原因可讀 |
| WD-13 | 自律不是永遠弱 | 自律艦隊有充足前置部署時間 | 主力艦可保持距離贏下第一戰，兼具風險 |
| WD-14 | 能量有「盾未破先傷亡」風險 | 一種有說明的穿盾彈頭 vs 高盾薄甲船 | UI 可在開戰前識別危機、提供撤退／對策 |
| WD-15 | 能量受供電與熱限制 | 連續束射、充盾、停火冷卻三組 | 不可能在功率不足時全部滿效；選擇有代價 |
| WD-16 | 材料文明不是無限子彈 | 長場交火與部分炮位損壞 | 材料艦可能仍有船體但缺彈／需要修甲 |
| WD-17 | 距離改變武器優劣 | 同艦三配置，近／中／遠戰距重播 | 無導引彈命中對距離敏感；導彈受攔截時間影響 |
| WD-18 | 專精深度有意義 | 高階單系 vs 低階針對性剋制 | 不得因低階反制標籤就必定秒殺高階專精 |
| WD-19 | 三學科獨立發展 | 單獨升材料、能量或自律 | 不會自動把其他兩個領域一起拉滿 |
| WD-20 | 指揮 AI 不出賣旗艦 | 自動戰鬥中遭遇反盾／飽和魚雷 | AI 會有效嘗試護衛／撤退而不是無預警自殺 |
| WD-21 | 戰鬥畫面可讀 | 關閉裝飾特效重播同局、顯示事件紀錄 | 戰果不因視覺粒子改變；失敗原因仍可理解 |

**以上 WD-06～21：狀態皆 Not run。** 需實作後才能記 Pass／Fail，缺執行環境時應標 Blocked，不得假裝已跑。

## 5. 三個最值得先做的比較實驗

### A. 「導彈、戰機、蟲群」對點防

用**同一艦隊、同等威脅預算**切換對手：純導彈、混合戰機、突擊蟲，並加一輪純主力艦。觀察有無目標時點防的行為、誤分配與飽和，不必第一版就做生態／感染模擬。

### B. 「三種文明的兩連戰」

用三種科研偏科的艦隊各打一場規模相近的戰鬥，**不能完全補給**地迎來第二戰。分別記錄炮彈／裝甲可用狀態、電容／散熱、導彈／無人機庫存，以驗證使用者提出的「自律母艦完整但戰鬥力見底」。**結果可能反駁假設**：例如能量過熱比導彈耗盡更嚴重，那就調整，而不是作弊把自律硬判最弱。

### C. 「別靠固定傷害倍率製造剋制」

保留**相同總成本、相同戰場條件**，改變防禦比重與交戰距離、是否有預置雷區。比較首戰勝率、剩餘戰力、殘餘物資、旗艦存活和玩家是否看得懂因果。要同時允許混合配裝，不是只做三種純色文明。

## 6. 最小戰鬥解析資料模型【提案】

每一筆攻擊事件至少應保留以下**語義欄位**；不規定使用任何語言或引擎：

| 欄位 | 用意 |
|---|---|
| attack_id、shooter_id、target_id | 戰鬥紀錄可追溯，不重複扣血 |
| delivery_class | kinetic／beam／missile；與彈頭分離 |
| payload_tags | kinetic、heat、nuclear、antimatter、field、phase…可複合 |
| projectile_or_carrier_id | 有飛行載具時保留 ID；射線則無宏觀載具 |
| travel_and_guidance_state | 位置、速度、轉向、剩餘燃料等（按類別選用） |
| interception_state | 偵測、分配、攔截、漏網；同一枚不被兩次擊落 |
| shield_effect、armor_effect、hull_effect | 區分受到不同層的作用 |
| resource_cost | 彈藥、能源、熱、PD 彈量、部署物、維修資產 |
| combat_event_result | 命中／未命中／攔截／模組失效／撤退／死亡等 |

射線不應為了相容資料模型而憑空產生「會被 PD 擊毀的導彈」。具體形狀、欄位型別與儲存格式尚待開發時評估。

## 7. 決策紀錄必留開口

正式數值**待決**：射速、命中、DPS、護盾容量與回復、PD 攔截率、預置雷數量、後勤成本、交戰距離、是否有研究樹、打撈後的武器可否仿造。**戰勝國**也不應因為玩家得到某件剋制道具就瞬間失去原本宇宙級強權地位。

記錄實測時請至少保留：版本、場景、隨機種子、初始艦表與科技、輸入命令、事件摘要、結果、是否通過。與 [17](17-prototype-test-matrix.md) 一樣，**設計文件不是測試通過證據**。
