# 會議歸檔｜三攻三防、偏科文明、異質艦隊與規則科技

> **本次整理日期：2026-11-16。** 核心素材來自先前標為 **2026-09-15** 的長篇科幻對話；今天由使用者指定寫入 `Gale0418/Odysstra`。這是**可追溯的摘要與設計遷移記錄**，不是該歷史對話的逐字存檔。不得把先前助理的延伸推論偽裝為使用者拍板。

## 對話如何走到六系

1. **太空碎片／低軌垃圾：**從失事衛星、碎片難以全追蹤、護盾是否能保護飛船談起。硬科幻基準是多層 Whipple 防護＋追蹤避碰；「藍色能量罩」可作科幻浪漫，但尚非現實通用防彈盾。
2. **裝甲與護盾的異常科技：**使用者列出從陶瓷、膠質、光子、白矮星、中子星到因果防禦，以及電磁、中性、時空、相位護盾。後來解釋「中性護盾」是想反制中子炮，不是聲稱存在「中性磁力」；中子與中性原子束不能混為一談。
3. **射線 → 另兩種攻擊：**原來不只射線，還有實彈與導彈，共**三攻三防**。完整親貼名錄是 15 實彈、15 射線、16 導彈；原名保存在 [19](../warfare-weapons.md)。
4. **實彈不能有自帶推進器：**使用者更正「核融合彈電磁投射炮」是普通電磁炮射核彈；「光子軌道炮」來自可作裝甲的《G之復國》光子材料，不是用 railgun 發射自由光子；只因彈頭很神奇不代表它變成導彈。
5. **點防不是沒用的 P 槽：**使用者不滿《Stellaris》式 PD 存在感低；原先後期構想包括**灑地雷與一次性自動崗哨炮塔**，讓防禦延伸至敵方導彈的中途；PD 也能打戰機、蟲群、無人機，沒小目標可打時支援射擊敵艦。
6. **別讓點防什麼都攔：**如果多層 PD 連高速實彈也可靠阻擋，裝甲失去價值；因此主要對位為**實彈↔裝甲、射線↔護盾、導彈／戰機／蟲群↔點防**。但現實物理並不支持攔砲彈概率永遠為零，遊戲採可靠性差異而非宇宙法則。
7. **科技偏科才是文明性格：**材料學長出實彈／裝甲、能量學長出射線／護盾、自律系統長出導彈／點防。玩家和 AI 都不需要同步爬六條樹，且單一低階剋制不應免費摧毀高階專精。
8. **自律文明的核心缺點：**不像光束只消耗能源，自律艦隊射出的是高價值完成品；母艦可以沒事但導彈／戰機／崗哨庫存見底。像航母編隊，擅偵察、佈防、遠程消耗與撤退，**不願被抓去正面決戰**。
9. **能量文明與 Advent 類比：**高度依賴護盾、船體較弱時可能「盾還在、船先沒」。本作要讓穿盾風險與功率／散熱限制可見，不能用突然秒殺取代戰術提醒。
10. **實彈文明的特色：**作者不反對「拿奇怪東西射出去」，這是材料文明的傳統笑點。改良應強化不同彈材造成的**不同機制**，而非刪除原來的光子、中子星與次元碎片炮。

## 旁支：這些不是六系中的第七、第八條

- **要塞炮：**使用者希望艦載武器之上能達多重宇宙級；特別提出**存在抹殺炮**。助理提出因果、真空、膜界、世界線等分級，但名稱表並非使用者親貼原始完整清單。
- **規則模組：**原始清單包含三千世界、事項疊加、重複觀測、時間備份式回溯；神級有存在抹殺、輪迴轉生、直死、境界、傷害除算、萬象修改（包括 1+1=3、氫密度變半、砍光譜、去掉零）。詳見 [22](../warfare-rule-modules.md)。
- **SCP 現實穩定錨：**用來想像對規則級攻擊的反制。僅借概念與回饋控制意象；不得把 SCP 的 canon 當成《Odysstra》設定或聲稱現實可用。
- **異質艦隊：**使用者挑出三種想像方向：**史萊姆；ELS＋Gray Tempest 式可重構群體；能量生命**。後來又提出反例：**有沒有能量無效、只怕物理的 Nullstone**，目前是額外候選，不是三家正式名冊。
- **死靈軍武化：**作者的對照不是幽靈船，而是《Homeworld: Cataclysm》**Beast 感染同化**；艦隊死亡與殘骸可能反成敵方資源，觸發「燃燒遠征」式清理、隔離與拒止戰略。
- **戰後地質：**艦隊毀滅會留下殘骸海、星環、蟲骸環、活性奈米塵；某些夠重、夠低速、軌道合適的碎片盤可能形成**小衛星**，不能宣稱所有會戰都自然養月球。詳見 [23](../warfare-exotic-fleets.md)。

## 被明確糾正的誤解

| 舊助手一度誤解 | 使用者真正強調 |
|---|---|
| 核融合電磁炮彈應移去導彈線 | **它就是炮射核彈**，無自推進 |
| 光子軌道炮是自由光子 | **光子裝甲衍生的實體彈體** |
| 中性護盾是「中性磁場」的物理宣稱 | **對中子／中性粒子炮的反制概念** |
| 點防只有反導用途 | **兼顧戰機、蟲群、無人機及對艦支援** |
| 後期 PD 必須升級攔截所有砲彈 | **不要讓 PD 搶走裝甲的角色** |
| 六條科技均衡升級 | **三個科研方向可以極端偏科** |
| 自律只是一條較長射程的導彈線 | **是以消耗性無人資產為主的航母式作戰文明** |
| 死靈術就是讓船骸站起來 | **更像 Beast 跨艦感染同化** |
| 「奇怪的石頭」讓實彈科技失敗 | **材料學就以投射奇異物質為特色**，需補差異化機制而非換掉原案 |

## 為什麼要寫進 Odysstra，而不是直接全部開工？

本作不是從零開始爬全宇宙科技樹的 4X，而是**戰敗遠征軍返鄉**。六系可賦予昔日友軍、海盜、戰勝國與古代遺產明確戰術差異；異質艦隊、現實錨、神級武器、戰場月球是**可選背景、稀有事件與長期內容庫**。仍以 **5 個左右測試星系的航行／補給／局部戰鬥／情報／敵方接管**優先。旗艦沉即 Game Over、共同母星是返鄉終點、抵達即 Happy End 均維持不變。
