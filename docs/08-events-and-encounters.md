# 08｜戰後遭遇與事件候選庫（64 組）

> **【內容庫】** 本頁是本次酒吧會議提出的 64 組遭遇「類型」，**不是正式版必須包含的 64 個任務，也不是每一局都會全部看到**。遇到事件首先應有地圖或遊戲內實體可互動；不要把每件事都做成《冰封龐克》式的強迫二選一選單。

## 生成與互動規則

1. **先有星系戰前用途與戰爭後果，再有事件**。商港附近容易有黑市與海盜，軍港容易形成割據，沒有礦產的貧瘠星系多半真的普通。
2. 事件由地點、現存勢力、補給需求、軍事資產、玩家艦隊編組、戰勝國接管時間共同決定。
3. 同一事件可以靠交易、偵察、戰鬥、逃離、搶劫、修船、協助友軍等實際遊戲行動發展，不要求每次都跳道德選項。
4. 經歷過的世界事件要存檔；被摧毀的軍港不能玩家跳出再跳回就自動復活。
5. 大型遠古遺產與毀滅級武器應極少見，尤其**不在全部普通星系塞「核彈」**。
6. 小故事可以用通訊文字＋圖示表現；大型戰役才需要較豐富的場景／AI。

## A｜過期星圖（01–08）

| ID | 事件 | 前因、玩家能做什麼 |
|---|---|---|
| A01 | 消失的星門 | 舊圖顯示交通樞紐，現場剩殘骸。偵察、修復可行性調查、繞路、拆零件。 |
| A02 | 友軍補給基地變海盜總部 | 商路秩序消失後被占；玩家可威懾、交易、突擊、避免接觸。 |
| A03 | 恆星系成為黑洞廢墟 | 戰時極端武器留下地理創傷；探索殘骸或改走航線，不能一跳就無預警全滅。 |
| A04 | 自動補給站還在服務 | 舊軍事識別碼可能獲准加油；高階設備可能另有身份、能源與廣播代價。 |
| A05 | 假捷徑導航 | 地方走私者販售過期或造假航路；驗證、偵察、識破，避免隨機必死。 |
| A06 | 兩份軍圖互相矛盾 | 戰前正式版與前線修訂版不同；新訊息能校準，形成探索推理。 |
| A07 | 免費星圖更新包 | 可能來自真實商會或情報陷阱；更新情報有價值，也可能洩漏艦隊興趣。 |
| A08 | 失落秘密航道 | 由戰時側翼路線或軍用跳躍點構成，能縮短路程但需驗證穩定性。 |

## 「同名不同命」：事件不是固定星系的必定劇情

例：戰前第九帝國船塢。戰後可能（甲）軍閥占領、仍能小規模修船；（乙）自動 AI 封鎖；（丙）被炸毀只剩稀有材料；（丁）已被戰勝國回收。只有地標、歷史背景與特殊資產存在是穩定的，**每局具體故事可變**。

## 玩家不必每局看到全部

建議把大型事件視為有條件的稀有劇情，普通事件當作城市生活。母星、出發星系和某些最低限度的導航關係可以保證存在，**但不能把 64 條候選直接設定成 64 個必經劇情**。

## 開發先後

第一階段實作 5～10 個可驗證的事件：海盜哨站、港口補給、被炸星門、可打撈殘骸、接管巡邏、軍閥交易；其他內容在核心玩法成熟後分批加入。

## 2026-11-16｜六張美食低價值星系事件候選【GE01–GE06】

使用者希望參考《美食獵人 TORIKO》的**完整可食生態系**：帝國若以軍工、物流及本族飲食習慣評估，可能把別族喜愛的食品世界列為低價值；**但大量珍貴礦物、高能晶體或重大戰略能源應正常被標高價，帝國不是地質笨蛋。** 完整可替換的世界與安全規則見 [WORLD-02](world-02-gourmet-ecosystems-and-imperial-low-value.md)。

這六張候選是 GE01 毒沼巧克力反轉、GE02 當地居民的食材交易、GE03 過期保育法令、GE04 看起來像食物卻真的有毒、GE05 舊圖正確標為高價值的晶礦星（負對照）、GE06 可食產品伴生的跨物種檢疫問題。**它們不是本章原有 64 事件的替換或強制追加，也不是 P-001 必做清單。** 低價值星系多數仍應沒有大事件，發現可口不代表安全，沒有要求造新料理系統或疫情模擬器。
