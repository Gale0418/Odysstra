# W03｜三大基礎科學、三種文明戰法與戰爭續航

> **來源：**使用者在科技樹討論中明確指出「科技不會均衡發展；材料學、能量學會被單邊點高」，並提出自律文明補給短缺與航母式避戰、能量文明「盾還在船體先沒」的典型場景。以下先記**使用者原意**，再列【提案】的系統化推演。這是《Odysstra》軍事世界觀和潛在機制，不是已經完成、已經平衡的遊戲。

## 1. 正確結構是「三門科學 → 六種軍事成果」

| 科研主軸 | 攻擊成果 | 防禦成果 | 典型長處 | 典型短處 |
|---|---|---|---|---|
| **材料／物質學** | 實彈武器 | 裝甲 | 高動量、厚重、強正面承傷、可持續互轟 | 需要物資補彈、修甲、推進大型艦體；長距離無導引命中不易 |
| **能量／場學** | 射線武器 | 護盾 | 快速投射、護盾恢復、場控制、專注能源即可兼顧攻防 | 供電、電容、散熱、護盾穿透與薄船體風險 |
| **自律／資訊系統** | 導彈、魚雷、無人攻擊載具 | 點防、地雷、自動崗哨、防禦網 | 偵察、追蹤、遠程投射、主動佈防、戰場塑形 | **有限載具與精密彈藥庫存、補充產能；主力艦不擅被迫貼臉決戰** |

**【已確認的高層方向】**科學領域可強烈**偏科**。例如材料學領先幾個世代時，實彈和裝甲可以很先進，但護盾還是舊式；能量文明反之。**「研究材料學」不等於同時免費解鎖所有材料炮與全部裝甲**，具體解鎖、機會成本仍待決。

## 2. 三種文明不是互相固定剋制，而是作戰哲學衝突

### 🔩 材料文明：戰列線、攻堅、消耗

**戰爭目標：把敵人拖進能穩定命中、承傷的決戰距離。**

- 具有實體投射、重甲、較強的正面壓力、固定防線與通道守備優勢。
- 艦船不一定速度慢，但**加重裝甲、巨炮和彈藥庫會對加速度、燃料、建造成本造成取捨**【提案】。
- 強在狹窄航道、要塞攻堅、硬碰硬的戰線與複數場交戰；但有可能被遠距消耗和機動拉扯。
- 彈藥並非無限：「只花子彈」是相對於發射完整導彈／無人機便宜，仍須金屬、加工、裝填、散熱與修理。
- 同等級實彈可能讓對手護盾消耗嚴重，但**不預先規定所有實彈必然穿盾**。

**失敗方式：**追不到人、被迫在劣勢射距交戰、船體持續損壞修不回、彈藥／推進資源耗盡。

### ⚡ 能量文明：護盾週期、場控制、熱力學

**戰爭目標：把距離和接戰時機控制在護盾／射線最有利區間。**

- 把科研與艦體空間押在反應爐、電容、場發生器、冷卻和射線平台。
- 護盾恢復速度與電力分配形成節奏：可以戰術脫離、讓護盾回復再交戰【提案】。
- 护盾／炮台可能競爭同一反應爐輸出；高功率束連射與高強度護盾同時全開也許不可持續。
- **使用者舉例**：《太陽帝國的原罪》Advent 一類高度依賴護盾的船，有時遇上穿盾攻擊會出現「護盾還在、船體先沒」；在本作中應轉化為**可被感知的薄船體／穿盾戰術弱點**，而非逐字複製第三方數值。
- 能量武器不消耗同型實體彈頭，**但消耗反應爐燃料／儲能、散熱餘裕、設備壽命與維護資源**。

**失敗方式：**被穿盾、局部系統過熱、反應爐保護停機、護盾回復不及、船體薄弱而突然潰敗。

### 🧠 自律文明：宇宙航母、遠程蜂群與前置補給

**戰爭目標：不接受對手定義的正面決戰；先用戰場佈署瓦解敵軍。**

- 導彈、無人機、戰機、攔截器、地雷、一次性崗哨與偵察網都是**有數量、有功能、有補充時間的外部資產**。
- 能在敵軍主力抵達前布設雷區、崗哨、誘餌和截擊網；持續調整襲擾與撤退航路。
- 典型戰術：**偵察 → 布防 → 誘敵 → 遠程飽和打擊 → 脫離 → 補充 → 再戰**。
- **核心缺點【使用者明確強調】**：續戰力低；即使母艦未受傷，導彈、無人機、崗哨等消耗品用盡，戰力也可能急跌。像航母編隊那樣**最怕外圍截擊資產消耗殆盡後，被逼進艦砲射程正面決戰**。
- 不能因為叫「自律」就當成任何消耗品能從真空無成本印出。前進基地、原料、製造設備、運輸線、時間與艦內庫容都是其戰略生命線。
- 航母類比並非「現實航母沒有任何自衛武器」；此處描述**以投射載具為核心的戰法與脆弱性**，不是嚴格套海軍武器射程。

**失敗方式：**庫存耗盡、產線被斷、無法回收戰機、點防網被掃清／誘餌耗光、後排母艦被主力突入。

## 3. 續戰力不能只用一個星等排名

某次會議將材料列「高」、能量列「中高」、自律列「低」，它只是**具體條件下的戰略推論**，不是普遍定律。實際要看：

| 變量 | 材料 | 能量 | 自律 |
|---|---|---|---|
| 短時間交戰 | 炮彈數、裝填、熱 | 電容輸出、護盾與束能競爭 | 可同時投射很多導彈／無人機 |
| 多場連戰 | 彈倉、修理工業 | 燃料、熱排除、場設備損耗 | **完成品庫存與回收損失** |
| 前線停補 | 補彈、重甲修復 | 重新儲能、冷卻 | 重新造製完整自律資產 |
| 低補給環境 | 是否有礦物與工廠 | 是否有可靠能源、散熱能力 | 最依賴補充工廠與後勤接駁 |
| 被迫近戰 | 重甲主炮常有優勢 | 看場控制／薄甲 | 典型航母型處境最吃虧 |

**建議衡量式【原型提案，非正式平衡】**：
- 自律剩餘攻擊輪數 ≈ 可用導彈數／每輪實際發射量；需扣除戰機可回收與重裝填。
- 材料剩餘輪數 ≈ 可用砲彈／射擊消耗，且別忘了裝甲／主炮損傷可能先令艦隊退出戰場。
- 能量剩餘射擊量不能簡單用「燃料／每發」算，因為**散熱容量與儲能恢復是可能先碰到的瓶頸**。

這是要驗證的模型，不是實際已測出的經濟數字。

## 4. 交戰距離才是最可能翻盤的變量

- 實彈：無導引彈的飛行時間與敵艦可機動空間越大，可靠命中越難。
- 射線：傳播快，但散射／繞射、指向精度、散熱及短時間功率會限制有效射距。
- 導彈：可以修正航路、繞後、待命，但越長距投送越需要燃料／推進性能，也讓敵軍有更多攔截機會。
- **資訊先手**：誰先發現、辨識、選擇是否接戰，往往比哪個陣營名義 DPS 較高更重要。
- **戰場約束**：星門、障礙、要塞、軌道與撤退路徑可能讓高機動文明無法永遠放風箏。

因此不要只做「材料剋能量、能量剋自律、自律剋材料」的硬式石頭剪刀布；同一對手在短距突襲、遠距消耗、要塞防守會有不同結果。

## 5. 偏科與混合科技【提案】

科技點數不是各項自動均分；三門學科是**資源投資的選擇**，也是文明戰略文化。

| 投資方向（示意而非固定門檻） | 代表艦型與戰略 |
|---|---|
| 材料主導 | 巨砲、重甲、攻堅／守點 |
| 能量主導 | 強盾、光束、脈衝戰、場控制 |
| 自律主導 | 無人航母、布雷艦、導彈巡洋艦、預置拒止網 |
| 材料＋能量 | 重力約束材料、複合裝甲、重型場炮 |
| 材料＋自律 | 變形材料、奈米自律製造、無人維修艦 |
| 能量＋自律 | 跳躍武器、電子／場控制防禦網 |
| 三學科皆高 | 罕見昂貴的綜合文明、古代戰略設施 |

**交叉學科先決條件【提案】**：中子星實彈需要一點場科技約束；跳躍導彈需要部分時空場研究；相位護盾要靠控制系統快速切換。其具體研發成本、關係圖與數字目前**待決**。曾提出「主科學 70%、兩個輔科各 15%」僅為說明投入的口頭例子，**不是確認公式**。

## 6. 如何把文明差異做成可玩的戰略選擇

- **材料玩家：**選定戰線、承受代價、逼出會戰；但需注意敵軍繞行和射程。
- **能量玩家：**控制交戰窗口、護盾充放與散熱；但要看得到穿盾危機，避免「藍條還在突然 Game Over」缺乏提示。
- **自律玩家：**預先偵察、決定何時佈雷／出擊／保留庫存、管理回收與撤退；但不能只有繁瑣補給點擊而無更好戰術結果。
- **混合玩家：**允許跨系混編克制對手，代價是研究與後勤複雜度。
- 敵軍 AI 同樣偏科：不能所有海盜最後都變全滿科技，也不能讓戰勝國輕易被一個初級專剋設備越級推平。

## 7. 在《銀河歸途》的地位

**【已確認】**背景是戰敗遠征軍返鄉，非創辦文明從零爬完整科技樹。科研專精可以用於**解釋沿路各勢力的艦船差異、改裝來源、配件稀缺、戰場情報與戰術選擇**。玩家是否擁有正式材料／能量／自律研發樹、可否自行全學、能否建前線自動軍工廠、可否部署大範圍地雷，目前都**待決**。

在 P-001 先只做「同級三類攻擊與防禦各一個、兩類科技傾斜的敵人、兩場連戰」去驗證：玩家能否看懂剋制、是否真的擔心自律彈藥、是否因科技偏科選擇繞路或撤退。詳細見 [24](warfare-prototype-tests.md)。
