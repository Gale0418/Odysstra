## 1｜《哆啦A夢：大雄的宇宙開拓史》到底有什麼線索？

**可以確認的作品概況：**
- 可亞可亞星（コーヤコーヤ星）是遙遠的開拓星，和大雄房間因超空間異常連接。
- トカイトカイ星的大企業ガルタイト礦業覬覦當地稀有礦產；ガルタイト是其礦業利益核心。
- 大雄在可亞可亞行動優勢與當地重力較低有關；**行星低重力 ≠ ガルタイト礦脈直接賦予他的超人能力**。
- 劇情後段的威脅達到「毀掉整個行星」的程度；詳細的核心破壞裝置與人物台詞以漫畫／電影原版為最終準據。

官方作品介紹：<https://www.tv-asahi.co.jp/doraemon/movie_collection/>（1981 原版與 2009 重製版請區分）；<https://www.tv-asahi.co.jp/doraemon_2017/story/0205/>

**本輪談話的強烈推論，但沒有原作證據證明：**
1. 公司有現成設備、威嚇流程與對警察的風險處理語言，令人聯想到既有 SOP。
2. **「熟練」可推測**行星裂解技術或設備已成熟、可能另有正常民用／採礦用途；**不能證明**這間公司先前曾秘密屠滅許多殖民星。
3. 「趁政府介入前一口氣執行、快速回收」是可能的企業犯罪策略，**不是已核對的角色正式台詞**。
4. 對話中提過「約一千光年／二百多個開拓星」的文明活動尺度；因尚未完成原作版本逐字核對，**只作待查歷史說法**。即使核實，也不能將「文明開拓範圍」偷換為「該礦業公司經營的一千光年」。
5. 原作並無本次可靠證據顯示擁有專用「行星碎片牽引光束」；它只是用來分析工程可行性的**假設設備**。

### 最有價值的重讀方式

**不是單純的「反派有殲星武器」，而是「某個極高科技、民間也有星際航行能力的世界，企業竟然討論以行星級破壞處理礦權糾紛」。** 這顯示戰略技術、民用工業、殖民法令與遠距離執法之間可能存在極不均衡的發展。

## 2｜為什麼炸掉星球不一定省錢：軌道力學的三個陷阱

### 2.1 把星球裂開，和把物質永久甩到太空，是兩回事

對質量 M、半徑 R 的近似球形天體，表面逃逸速度：

**v_escape = √(2GM/R)**。

- 破壞岩石結構並不自動消除自引力。
- 碎片速度低於相對整體質心的逃逸條件，可能因碰撞與重力**重新聚集**。
- 碎片速度足以脫離原天體，則會形成擴散的碎片群，後續掃描、追逐與運輸成本可能暴增。
- 受恆星引力束縛、繞行新軌道與「原地待著」是三件不同的事。星球解體時，碎片通常仍保留原先繞恆星運動的速度分量，還會疊加爆破造成的速度差。
- 必須區分「碎石團」「塵雲」「行星環」「同軌道碎片」「真正逃逸於恆星系之外」；這些結果不是同一個。

如果只在**忽略引力、速度恆定**的示意條件下，用 d = vt 計算：
- v = 1 km/s，1 天約移動 86,400 km。
- 同速 365 天約 31,536,000 km。
- 此值不是實際碎片的完整軌道積分，更不是所有礦石都會飛到該距離；它只是展示**很小的相對速度差隨時間也會造成可怕的搜尋半徑**。

### 2.2 能量成本不會因為一句「核心爆破」就消失

近似均勻密度、非旋轉球體的重力束縛能：

**U ≈ 3GM²/(5R)**。

以地球做物理量級示意，U 約 **2.2 × 10^32 J**。這不是可亞可亞星的實際數值，也不是任何原作武器的標示威力；可亞可亞質量、半徑、密度與裝置機制均未知。

真正需要區分三種行動：
- **局部地殼破碎**：破碎／爆破成本由岩性、深度與局部工程決定；不等於完全解體。
- **引起行星整體失穩或崩壞**：需交代如何維持碎片可回收；遠超一般礦山爆破。
- **將全部或大多數物質送出原重力井**：需考量整體束縛能量級；不應拿「只破岩石」的成本充當完全分散的成本。

**必要修正：** 先前聊天曾把「碎得越徹底越好、飛得越慢越好」當理想。這只在**存在捕捉、牽引、重新配置或人工束縛手段**時成立；完全自由的碎片若速度不足，仍會重聚，因此不能同時免費得到「永久散開」和「全部待命在原地」。

### 2.3 碎掉後的副作用也是錢

除了直接損失礦產，還要考慮：
- 大量低品位岩塊遮蔽高價礦脈，增加分類成本。
- 碰撞破碎帶來高速次生碎片、航道危險、回收艦損耗。
- 對同星系衛星、基地、星門、軌道設施的損失。
- 可居住環境、原住民／殖民人口、土地、工業及未來開採權的價值歸零。
- 大規模可觀測天體事件帶來執法關注，難以長時間隱藏。
- 若反重力礦物價格極高，還必須考慮**超額供給是否導致售價下跌**。

## 3｜「爆星採礦」什麼條件下才可能有利可圖？

把決策寫成兩個目標：**合法企業最大化長期淨現值**；**非法企業可能最大化執法干預前成功帶走的淨值**。不要混為一談。

可用簡化的虛構概念式：

**Expected Net Gain = p_success × [recovered_quantity × net_sale_price] − extraction_cost − recovery_cost − transport_cost − equipment_loss − time_cost − expected_sanctions − destroyed_asset_value**。

其中：
- recovered_quantity = mineral_inventory × effective_access × separation_yield × capture_rate；
- effective_access 衡量是否真能碰到深部礦物；
- capture_rate 衡量碎片會不會跑掉；
- net_sale_price 必須考慮市場承受量，不宜自動等於少量零售價；
- expected_sanctions 不只是罰金，還包括犯罪後的軍事追擊、公司資產被凍結與船隊遭扣押；
- destroyed_asset_value 對可居住／已開發世界可能極高，對貧瘠無人天體可能較低。

### 三個比較方案

| 方案 | 優點 | 主要代價 | 適合情況 |
|---|---|---|---|
| A 慢速定點礦業 | 回收率容易優化、持續產出、不破壞全部資產 | 需要礦權、時間、補給、安全維護 | 合法、長期、可預測市場 |
| B 受控區塊挖掘／EVE 式牽引 | 只取值錢的區塊、受控搬運、可分段結算 | 需要強大牽引、偵測、精準工程 | 高科技、希望降低物流與地殼成本 |
| C 快速行星級裂解 | 立即接觸深部、可能一次大量變現、迅速建立既成事實 | 能量與工程成本高、碎片逸散、聲量極大、政治後果不可逆 | 特殊礦物極值錢、時間窗口短、非法暴利或末日級行動 |

**不能只因 C 最快就說它最賺。** 當成本高、碎片不受控、政府有立即干預能力或礦物不夠稀有時，C 很可能是最糟選擇。

## 4｜「政府發現以前炸完」的理論為什麼比「炸掉比較省」有力

假設：
- T_detect：外界得知可疑行動並確認事件所需時間。
- T_mobilize：執法／軍事決策和集結的時間。
- T_arrive：足以阻止行動的兵力到場時間。
- T_execute：部署、拆解、抓取值錢物質、裝載、撤離所需時間。

一個便於思考的成功條件是：

**T_execute < T_detect + T_mobilize + T_arrive**。

但這**不是保證**。要把同時偵測、路上攔截、緊急超空間跳躍、保護區法律、遠端凍結企業資產、保險賠償與追討戰利品等風險另行計算。

**真正的策略不是避免被看見，而是在擁有阻止能力的政府到場之前完成不可逆行動。**

不過很重要：
- **星球毀滅比普通偷挖礦更顯眼**，也可能提早觸發偵測。
- 若政府 FTL 機動非常快，或天體防禦站足以遠程阻止，爆破方案便不成立。
- 若回收需要數年，而破壞只需幾分鐘，「炸完」不等於「賺到」。
- 對方要是有全圖監控，**更不能**假設地點偏僻就自動隱形；可能只是追不追、先追誰的取捨。

### 三個可能結論（必須保留反方）

1. **最強正版：非法清倉**：企業已暴露，行政／法律風險急升，寧可失去大部分礦也要在最後窗口裝走精礦。
2. **最強反方：整顆炸掉絕對賠本**：運輸量、能量、碎片和政治制裁完全超過所得，反派只是策略失誤或編劇追求高潮。
3. **值得考慮的第三案：合法設備被濫用**：受控拆星設備原本可以處理無人天體；企業為規避礦權／清場，非法把有人居住的開拓星當成無人礦區。

**本輪首選的世界觀補完：第 3 案＋第 1 案的執法時間壓力；仍是推論，非《宇宙開拓史》官方答案。**

## 5｜EVE Online 月礦：真正給工程師看的答案

EVE 的 Moon Mining 在官方支援頁有明確的可操作流程：

1. 在可用的月礦信標旁建造 Refinery，安裝 Standup Moon Drill。
2. 選擇約 **6～56 天**的抽取週期；較長週期可取出較大岩塊。
3. 月球鑽機向月球發射特殊牽引／抽取效果，把**可控岩塊**拖到精煉設施附近。
4. 抽取週期完成後，再把岩塊**破碎成小行星**供礦船開採。
5. 餘下的岩石帶維持有限時間，企業有實際的抽採紀錄。

官方：<https://support.eveonline.com/hc/en-us/articles/115005404229-Moon-Mining>

這與「整顆星球炸成毫無控制的碎片」差別極大。EVE 的核心優勢不是爆炸威力，而是：

**先固定可控料流 → 抽出特定岩塊 → 運到加工空域 → 再破碎採礦。**

本輪對話曾以 EVE 的 **Tractor Beam** 類比《宇宙開拓史》可能需要的牽引能力，但**EVE 確定有，不等於哆啦A夢原作確定有**。

## 6｜《群星》到 2026 年真的有兩種以上「破壞天體換收益」

**版本界線：截至 2026-11-16，PC 正式版已到 4.5.4；預告 2026-11-23 的 Willpower／4.6 尚未發售。** 以下機制為既有內容；數值可能隨後續平衡更動。

### 6.1 Star-Eater：吃掉一個恆星系，收集暗物質

- 出自《Nemesis》危機路線；後段取得 Star-Eater（噬星者）。
- 使用 **Star Cracker** 對恆星發動攻擊，使目標恆星坍縮成黑洞，並毀掉其所在**恆星系**的天體／可居住世界。
- 可取得大量**暗物質**，供危機艦船及 **Aetherophasic Engine（以太相引擎）**等需求使用。
- 所得是 Stellaris 的遊戲資源數值，**不等於從現實恆星炸裂的質能公式可直接推導出同量的可售商品**。
- 若是複星系統，相關規則可能影響整個系統；現實中的雙星與遊戲戰略節點不可混用。

機制參考（社群整理；官方遊戲內數值以目前版本為準）：<https://agentmystia.github.io/StellarisWiki/Star-Eater.html>

**經濟意義：** 不是普通礦業最大化市場收益，而是**危機帝國用永久消滅星系的方式，直接換取稀缺戰略資源與末日工程進度**。這是「資源收割」和「殲滅武器」合體，**不能誤稱一般合法商業採礦**。

### 6.2 《Nomads》Planetary Reprocessing：把非宜居天體榨乾

2026-06-15 推出的《Nomads》及 4.4「Pegasus」擴展遊牧方舟的資源採集。官方開發資料將幾種抽採方式分開：

| 工法 | 官方公布的 Resource Harvesting Efficacy | 資源枯竭標記時間 | 目標後果 |
|---|---:|---:|---|
| Harvest Resources | 100% | 20 年 | 一般採集與枯竭效果 |
| Planetary Strip Mining | 250% | 50 年 | 更強的資源榨取 |
| Planetary Reprocessing | **600%** | **200 年** | 轉化成 **Shattered World**，原有礦藏全部清除 |

**極重要的口徑：** 600% 是對「該遊戲的基準採集計算」之倍率，不是「抽走行星總質量的 600%」，也不是所有玩家都能不受限制使用。開發資料標示需要對應 Arkship 的 **Planetary Reprocessor Spinal Mount**；此類採集目標為非恆星、非宜居世界類別，對領土主權也有外交後果。

官方開發資料（Steam／Paradox 開發日誌鏡像）：<https://store.steampowered.com/news/posts/?appids=281990&enddate=1781175608>；發售公告：<https://www.paradoxinteractive.com/media/press-releases/paradox-interactive/paradox-interactive-launches-major-expansion-and-free-update-for-stellaris>

**經濟意義：** 這才真正像「工業化的天體拆解」。賺的是**一般及戰略資源的立即變現**，代價是將可持續利用的天體變成破碎世界，犧牲後續開發價值。

### 6.3 另外兩個常被搞混的《Nomads》功能

- **Stellar Engine**：對恆星／氣態巨行星施加高能暗物質相關處理，以提高能源與研究資源產出；氣態巨行星可變成原恆星（protostar）。**不是 Star-Eater 式整個恆星系爆炸**。
- **Stellar Cannon（恆星級巨砲）**：消耗巨大能源庫存遠距離打擊敵方星系的巨構武器；它是武器，而非行星拆解賺礦的標準流程。

《Nomads》官方發售公告同列巨砲等功能，上述 Stellar Engine 細節見開發日誌。**不要因名稱都有 stellar 就混成「一座設備可賺錢又能炸宇宙」。**

### 6.4 戰略收益的分界線

| 機制 | 毀滅尺度 | 收益 | 核心玩法意圖 |
|---|---|---|---|
| EVE Moon Drill | 月球取出一塊岩體，月球仍在 | 可開採月礦 | 長期工業物流 |
| Stellaris Planetary Reprocessing | 一顆適用天體變成破碎世界 | 大量即時資源 | 遊牧工業與長短期收益取捨 |
| Stellaris Star-Eater | 恆星及整個恆星系毀滅 | 大量暗物質 | 危機升級／末日工程 |
| 《宇宙開拓史》企業計畫 | 有人開拓星面臨整體毀滅 | 意圖獲得ガルタイト | 劇情威脅；回收流程未詳 |
| 佛利札星球貿易 | 通常**不希望**毀掉待出售星球 | 可出售／占有的行星 | 侵略、清場、地產轉售 |

## 7｜佛利札的財務報表：他是星球房仲，不是炸星發電廠

《七龍珠》佛利札勢力的核心商業模型是**攻占有價值的星球、處理其原住居民與防禦力量，將可利用的行星交給／賣給需求者**。Heeters 在《Dragon Ball Super》替佛利札取得可入侵的行星；這是一條供應鏈，並非「炸毀行星後收能源」。

官方 Dragon Ball 關於 Heeters 的描述：<https://en.dragon-ball-official.com/news/01_2685.html>

經濟式可簡化為：

**Profit_planet_trade = sales_price_of_usable_planet − conquest_cost − logistics_cost − political/risk_cost**。

一顆宜居世界是**庫存商品／收益資產**。若把它炸碎，該商品大半價值即消失；這通常違反出售目的。

佛利札摧毀貝吉塔行星更接近**軍事安全、支配秩序與可能反抗風險的決策**，不是正常每筆星球買賣必須經過的加工步驟。

**三種商業模式請勿混成一種：**
- 星球貿易：保留行星價值並使其可轉手。
- 礦業拆星：只保留高價礦物，犧牲行星整體價值。
- 危機噬星：消滅星系換取戰略資源／末日工程進度。

## 8｜回到 Odysstra：這套世界觀可以怎麼用？【提案／內容庫】

### 原則先確認

- **已確認**：玩家有百艘左右相對完整的軍團、約十萬同鄉、自由採礦／貿易／搶劫／造船、停止更新的軍圖、戰勝國全圖監控但追擊有優先度、母星即 Happy End。
- **未確認**：玩家有可用殲星裝置、可拆行星的科研樹、牽引光束、暗物質貨幣、長期星際黑市供應商。
- **不建議偷偷新增**：全系統行星物理模擬、無限材料複製、建造 Star-Eater 的必做主線、把每顆普通星系變成可爆破金礦。
- **最有價值的世界觀假說**：前宗主國曾將局部天體移動、無人星拆解、工業資源轉運常態化；戰爭後舊設備落在已失去中央監管的友軍星域。

### 四個候選遭遇（可拆分／可不做）

| ID | 原創內容 | 玩家能做什麼 | 對既有循環的作用 |
|---|---|---|---|
| PM-01 | **失業的行星處理廠** | 拿燃料與設備換修船材料、購買補給、賣掉座標、直接繞過 | 以一個星系事件呈現超文明工業 |
| PM-02 | **非法清倉的採礦財團** | 販售情報、救援運輸船、趁亂打撈、與當地政府交易、保持中立離開 | 事件由利益、時間和地方政治推動，不強制道德選項 |
| PM-03 | **受困的碎石牽引站** | 協助重新控制礦團、拆零件、冒險搶占空域、放棄 | 以控制區／時間／貨艙上限取代完整 n-body 模擬 |
| PM-04 | **被刪掉的恆星系** | 舊軍圖仍記載星門與港口；現況是黑洞／失落航路；調查原因或繞道 | 直接展示「舊圖真實但停止更新」核心敘事 |

可有極罕見的古代超級設備，但**不把前宗主國所有星域都設為殲星事故現場**；大量星系仍應普通、平靜、可以路過。

### 低成本原型轉譯【提案／Not run】

首版**不必實作炸星球按鈕**。可以先用單一普通星系與幾項抽象狀態驗證：

- old_map = 戰前標記為「民用礦業園區」。
- current_state = 「停工／被接管／已拆解」三種之一，並保留歷史。
- salvage_available = 待決數值；受玩家決策與世界時間影響。
- legal_owner / ownership_dispute = 可交易／搶劫／放棄的背景判斷。
- enemy_attention = 玩家運走高價古物或鬧出大動靜後，可能影響戰勝國優先度（不是消失監控）。
- route_status = 依實際被毀設施與航道改變，始終檢查返鄉仍有可行路線。
- acquired_materials = 只轉換為[第 05 章](05-travel-economy-and-logistics.md)已有的「原料／燃料／可延後工業材料」，不要先加十二種專用礦石。

**最小可測假設：** 玩家看見「高價值但可能引起更大關注」的打撈機會，是否會在返鄉時間、資源與戰略危險之間做有趣的取捨？

| 原型案例 | 驗收觀察 | 狀態 |
|---|---|---|
| PMT-01 | 不碰礦場仍能沿其他路線返鄉；不是強制任務 | Not run |
| PMT-02 | 大量打撈需要耗時／貨艙條件；不能免費無限挖出最強艦 | Not run |
| PMT-03 | 戰前地圖記錄不被現況覆蓋；現況與觀測日期正確更新 | Not run |
| PMT-04 | 收益與戰勝國注意力有因果；全圖監視不因躲進星雲而消失 | Not run |
| PMT-05 | 高科技裝置可被發現但未必可啟動、可維修或可複製 | Not run |
| PMT-06 | 旗艦被擊沉仍按既有 Game Over 規則處理 | Not run |

這些是**未執行的新增測試構想，不改動原[第 17 章](17-prototype-test-matrix.md)的既有案例總數與狀態**。

## 9｜最終裁決與仍待研究

### 這場討論最有價值的六個結果

1. **炸掉天體不會自動讓礦更容易回收**：地殼破碎、永久解體、碎片逸散與運走材料是完全不同的工業階段。
2. **牽引與料流控制可能比殲星能量更值錢**：如果控制不了碎片，爆星只是把礦倉撒成太空塵。
3. **政府反應時間可改變非法礦業經濟學**：企業可能不是求最佳總回收率，而是求在被制止前完成一次性變現。
4. **從業熟練不等於已證實連環炸殖民星**：成熟的合法拆星工業遭到濫用，是更少假設、也更可怕的補完方向。
5. **《群星》真的將「摧毀世界／星系換資源」做成不同機制**：遊牧行星再處理 vs 危機 Star-Eater 的目的、規模、報酬和代價不可混用。
6. **佛利札恰好是反例**：他的財產主要是**保持可用、可出售的星球**；炸星更像清除戰略威脅，不是正常的營業現金流。

### 未決／需要原作與遊戲內再次查核

- 《宇宙開拓史》不同原作／電影版本對核心破壞裝置、回收方法、官方警力、礦業公司規模與「一千光年／二百多顆」數字的逐字證據。
- 原作是否有實際牽引光束／大規模自動篩礦；**目前無足夠證據**。
- 《群星》後續版本是否重調 Planetary Reprocessing 的 600%／枯竭時間及 Star-Eater 的暗物質收益；本文記錄 2026-11-16 已查到的機制，**不是永久保證的遊戲數值**。
- Odysstra 是否要實裝任何玩家操縱的天體級工業設備：**待決**。僅因這些設定好玩，就將它們寫成必做系統是典型開發範圍失控。
