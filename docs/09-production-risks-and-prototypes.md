# 09｜逆向避雷、最小可玩原型與驗收

## 首要失敗假設

**「先把世界觀、彩蛋、30 個地標、70 種普通星系、古代巨構和所有玩法系統一次做完，遊戲就會自然好玩。」**

逆推：設定越厚 → 系統越多 → 戰鬥、航行與經濟從未實測 → 遲遲沒有可玩原型 → 返工與資源耗盡。**此為假設風險，不是已發生的失敗**。

### 十項風險與防禦

| 風險 | 為什麼嚴重 | 防禦／先驗證 |
|---|---|---|
| 1. 百艦 2D 即時戰鬥 | AI 避障、射界、群組、目標選擇與效能吃工時 | 先 5～10 艘戰鬥，逐步壓測 20／50／100 艘 |
| 2. 自動戰鬥變成看戲 | 玩家的編組與策略無法改變結果 | A/B 測戰前陣型、集火與戰中少量命令 |
| 3. 旗艦 AI 自殺 | 使用者指定旗艦沉即敗，錯誤 AI 導致無理死亡 | 明確保護模式、危險預警、撤退路徑 |
| 4. 戰勝國推進封死所有路 | 沙盒變單向倒數，玩家缺少選擇 | 讓軍力依航道和距離移動，保留可準備的路線替代 |
| 5. 接管區全圖瞬移 | 全圖監控被誤做全圖瞬間執法 | 情報、優先度、路程與兵力分開模擬 |
| 6. 無限吸太陽／無限挖礦 | 交易、搶劫、探索都失去價值 | 補給需時間或設備，產能與物流形成合理取捨 |
| 7. 百艘起始艦隊倒掛難度 | 普通敵人太弱，開局無挑戰 | 用護航、維修、情報、目標衝突設計挑戰，不強制殘血 |
| 8. 程序生成只是換貼圖 | 70 組普通星系與地標沒有遊戲差異 | 戰前用途→戰損→現況；允許真正安靜的星系 |
| 9. 遠古神器通膨 | 每三跳撿到超武，所有進程和世界尺度失衡 | 分級、罕見觸發、操作／維護成本、敵國回收反應 |
| 10. 操作與存檔失控 | 100 艘船、動態星圖和多勢力會造成資訊爆炸 | 群組 UI、區域模擬、可重現種子與事件持久化 |

其他風險：版權／商標、引擎選錯、未測試手機效能、設計文件當作完成品、過多黑色幽默破壞返鄉感，以及在母星硬加強制悲劇。

## P-001：先做一段可玩的返鄉戰役【提案】

**目的：** 驗證「舊地圖規劃 → 自由航行 → 補給與戰鬥／避戰 → 世界隨時間接管 → 艦隊成長」是否真正有趣，不是驗證 30 顆星系的文案能寫多長。

### 最小戰區

| 節點 | 角色 | 可玩驗證 |
|---|---|---|
| A：出發前線 | 軍團編組、簡化舊軍圖 | 看懂起點、母星方向、旗艦與人口 |
| B：商港 | 貿易補給、情報 | 補給包購買與價格／關係 |
| C：軍閥要塞 | 交戰或交易 | 自動戰鬥、撤退與戰利品 |
| D：無人礦區 | 原料／燃料採集 | 自由停留、補給成本與時間推進 |
| E：出口星門 | 戰勝國逐漸接管 | 繞路、時機、情報、過境 |

五個節點間至少有**兩條可行的路徑**，能回頭；路線不必全朝同一方向。

### 第一階段只做

- 2D 星圖點選、可重現的航路及停靠。
- 簡化軍團編組、旗艦標記、人口／艦船／載員容量。
- 燃料、原料、交易、恆星採集、簡化修復與打撈。
- 一場足以測試戰術的自動交戰；最少一個戰前指令與撤退。
- 戰前舊圖＋部分未知現況，玩家偵察後更新。
- 戰勝方基於時間推進接管一個重要區域，不瞬移抓玩家。
- 旗艦沉沒 Game Over，出口達成測試完成，狀態可存讀。

### 第一階段不要做

不做完整百艘高精度即時戰鬥、十萬個角色 AI、完整 4X 政權、所有 30 個特色星系、全部 64 個事件、所有遠古超武、多語言商店、全面 3D 登陸、複雜道德議會與母星後日談。

## 驗收問題（測什麼而不是喊進度）

1. **策略分歧**：同一張圖是否有合理的「戰鬥直通／補給繞道／先採礦再出發」等不同方案？是否都不是唯一必敗？
2. **資訊價值**：老軍圖提供足夠歷史線索，但過期情況能讓偵察有意義？玩家是否知道情報何時最後更新？
3. **戰鬥可理解**：玩家知道勝負與旗艦危險原因？保護／撤退指令真的有效？
4. **後勤張力**：太陽吸燃料與購買補給都可用，但不會把其他玩法價值完全抹除？
5. **接管公平**：玩家能預見敵方行動並準備，不會被全圖瞬移或無預警必死？
6. **世界持久**：打掉海盜後，該處控制權／活動會留下可見影響；重新進出不會刷新成原樣。
7. **重玩意願**：同樣骨架、不同戰後狀態是否值得玩家改走另一條路？

## 設計失敗怎麼修

- 無聊：先調「一次航行決策能否改變風險」，不是先加 100 張插畫。
- 自動戰鬥很無聊：增加有回饋的有限命令，不立即投入逐艦微操。
- 敵國推進太強：調戰略優先度、調兵可及性與情報可見度，不直接取消世界壓力。
- 經濟太輕：測補給速率與停靠成本；太重：減少資源種類／繁瑣操作。
- 人口無存在感：讓戰損影響返鄉結算、艦船載員與人力，不轉向十萬 NPC 模擬。
- 玩家不想回家：允許沙盒偏航，但不承諾當前版本具備完整 4X 國家治理。

## 優先序與範圍凍結

**P0**：星圖移動、旗艦、戰鬥小切片、燃料原料、敵國接管、存讀檔。  
**P1**：編隊管理、回收修船、交易、偵察、局部勢力反應。  
**P2**：更多地標、豐富事件、古代遺產、基地建造與政治互動。  
**P3**：大型艦隊多戰場指揮、跨星系宏觀經濟、複雜外交、額外結局與擴充。

不要承諾工期、產量、完成率與性能數字；數據尚待實測。先測 P0 再考慮擴大。

## 尚須正式決策

使用引擎／平台（Web／Canvas／WebGL 或其他）、單場艦船上限、是否提供手動旗艦控制、部署點數還是編隊、指令粒度、資源分類、存檔政策、戰勝國 AI 模擬精度。詳見 [11](11-decisions-and-open-questions.md)。

## 整併後的原型範圍閘門

五個測試星系中的「出口」只是切片完成點，不把正式終點改成撤離星門。最低玩法優先序不變；W01～W07 是可挑選的戰鬥素材，不要求把所有科技階段和配方做完。

模組武器可先只試一個有限分裂導彈配方、一個貫穿實彈、一個脈衝射線，加上既有點防。若它們不改變玩家戰術，只增加選單工作，應縮小語法。具體組合、觸發預算和學說批次配裝見 [W07](warfare-modular-blueprints.md)，新增 WB 案例全未執行。

本倉庫自動文件檢查和其單元測試屬於**文件品質工具**，與 QA／WD／WB 的遊戲驗收分開計數；CI 綠燈不等於 P-001 已完成。
