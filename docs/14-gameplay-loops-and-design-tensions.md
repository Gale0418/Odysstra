# 14｜玩家循環、自由度與真正的策略張力

## 玩家究竟每天在做什麼

**【提案中的核心循環】**
讀軍圖並挑下一段航線 → 決定編隊／是否派偵察 → 航行 → 觀察戰後現況 → 交易、採集、維修、回收、襲擊、戰鬥或直接離開 → 時間與世界勢力持續變化 → 儲存航行紀錄 → 再選下一段。

這是**自由航行的艦隊沙盒**，而不是每跳必須按三個劇情選項、也不是地圖必須向右不能回頭。

## 以五種不同玩家路線驗證自由度【提案】

| 玩家風格 | 行為 | 自然代價與回報 |
|---|---|---|
| 低調返鄉 | 普通艦＋補給艦，趕路、修整、避開主戰場 | 相對不受戰勝國優先關注，但軍力與載貨有取捨 |
| 作戰派 | 帶正規主力，打擊海盜與地方軍閥，收編戰利品 | 過境軍事能力強，補給／戰損／敵對關係較複雜 |
| 工業派 | 留在無人資源區採礦、修船造船、分遣隊合作 | 能增強艦隊，卻花費遊戲時間，可能碰到接管局勢改變 |
| 泰坦作死派 | 開局或路上擁有遠古級主力艦，強行通過高價值星系 | 局部超強、敵國高優先度、稀有維修難題 |
| 自由漂泊派 | 不急著回家，留下建基地、經商或當軍閥 | 沙盒容許，但完整 4X 帝國模擬目前不是承諾 |

不同路線的核心是**成本、情報、軍力、航線選擇**，不是善惡點數和每天開政治會議。

## 核心張力一：知道路，不知道路況

歷史軍圖很詳細，但停更。玩家可以賭舊星門仍可用，也可以派快艦先行核實。每多做一次偵察，就消耗人力和時間；帶百艘重艦盲跳則可能浪費整隊燃料。**偵察不是強制流程，是有價值的策略工具**。

## 核心張力二：有軍力，但打不贏真正的勝利者

玩家在昔日盟友領土可能是地方強權，但戰勝國是全銀河霸權。弱敵會讓路，強敵要靠繞道、準備、協商或撤退。**不限制玩家變強，也不讓普通採礦掛機就能一夜推翻遠古帝國**。

## 核心張力三：待久一點會更強，世界卻不會等

補給可以買或吸太陽，原料可以採礦。重點不是強迫玩家餓死，而是**花在採礦、造船、修船上的遊戲時間，也讓軍閥、海盜、戰勝國繼續行動**。有古代資產出現時，戰勝國甚至改派軍隊優先回收。

## 核心張力四：旗艦是你的命

百艘作戰軍團很強，但玩家就在旗艦上。旗艦沉沒即敗。需要有用的護航、撤退與清楚威脅警報，不能只讓司令在全自動 AI 鏡頭前看旗艦送頭。

## 核心張力五：人是資產，但不是繁瑣 NPC 模擬

十萬名同鄉作為軍團人口數字存在。玩家配船時若沒有足夠居住後勤艦，**起始人口就少**；作戰損失與救援友軍能改變實際返鄉人數。重要老兵可透過少數艦長／參謀代表，而非十萬份角色檔案。

## 簡化的假想遊玩一段【僅示意】

1. 旗艦讀到戰前軍圖：前方三跳有皇家補給站，右側偏遠無人系有少量礦。
2. 偵察隊報告皇家補給站可能已成軍閥前哨，玩家仍可通過但高風險。
3. 玩家選擇改走無人系，恆星採集燃料、回收一艘舊軍艦；在那裡多待幾個遊戲日。
4. 戰勝國在相鄰星域發現古代軍備，調整接管方向；地圖更新當前接管情報。
5. 玩家選擇低調離開、趁亂打撈高階零件，或回頭交易。**每條路都在玩法上成立**，無須劇本懲罰不正確選擇。

## 失敗與成功

- 旗艦被擊沉 ⇒ Game Over（已確認）。其他敗因／存檔細節待定。
- 抵達共同母星 ⇒ **Happy End**（已確認），按實際人口、艦船與旅程記錄結算。
- 玩家想待在銀河別處 ⇒ 可長期自由遊玩（已確認方向）；目前不需為此另造建國大結局。
- 目標不是「把所有事件看完、把所有星系征服」；一局沒遇到一些地標劇情是正常的。

## 用來檢驗好玩與否的問題

1. 不看任何劇情文字，玩家是否仍願意比較兩條航路？
2. 攻擊軍閥、買補給、去無人系挖礦，是否都是有實際收益的路線？
3. 自動交戰時，一個合理編隊命令能否救下旗艦或運輸船？
4. 戰勝國知道玩家位置卻不立即追擊的理由是否可見、可推理？
5. 玩家從戰敗軍團到返鄉英雄的成長，是否主要由自己行動達成？
