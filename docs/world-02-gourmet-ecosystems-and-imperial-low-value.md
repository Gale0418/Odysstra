## 1｜真正的設計原則：物理共通，生理／味覺不共通

**【使用者最新明確修正】** 不能把「前宗主國對美食不感興趣」擴大成「前宗主國連物理與戰略礦產都不認識」。同一宇宙的物理規律可以讓不同種族辨識高能物質的潛力、礦物分布、航道、能源、巨構材料等客觀價值；**價值仍須區分偵測能力、開採／運輸成本及當時技術用途**，但無合理原因時不應把滿地珍貴礦物或高能水晶的星系歸入低戰略價值。

| 對象 | 什麼能跨種族比較 | 哪裡可能因物種／文化不同 | 舊軍圖合理分類 |
|---|---|---|---|
| **高能晶體／戰略礦物富礦** | 能量與材料特性、含量、純度、利用成本、軍工需求 | 技術適用與當時運輸經濟可能不同，但不是單純口味差 | 若大量可利用且具戰略需求，**高價值** |
| **高通量星門／能源設施／船塢** | 航道位置、物流吞吐、輸出功率、可用軍工產能 | 政治權利、控制與維修能力因勢力而異 | 通常**戰略高價值**，戰後實際能否使用另算 |
| **一般無礦無設施的異常生命世界** | 物種數量、化學組成、星球環境、可存取資源 | 可食性、風味、感官偏好、宗教與飲食禁忌 | **可能是軍事／工業低價值**，即使非常好吃 |
| **生態系產生的新奇芳香／糖脂／蛋白質** | 化學性質、產量、生化結構可測 | 哪種生物能代謝、覺得香、能加工、安全或有市場 | 需分開標記「帝國供應價值」與「我方美食價值」 |
| **劇毒／致幻／過敏性物質** | 分子與濃度、物理化學傳輸可測 | 生理受體與代謝能力不同，物種 A 的毒不等於物種 B 的毒 | 標明**受影響物種、樣本、接觸途徑**；不能寫成全宇宙絕對毒 |

**三項不可偷換：**「星系層級的軍事／工業價值」≠「行星層級的可食性」≠「對哪個物種而言有毒／好吃」。而舊軍圖的實測資料也不應被玩家最新品嘗結果覆寫；需保留當年版本及現時補充評價。

### 帝國給出 LOW 的四種合理原因【提案】

1. **沒有可用戰略資源**：少礦、無軍港、航路不重要；即便盛產香甜水果也不因此提升軍工指標。
2. **食物經濟權重很低**：食物列印器與完善供應鏈讓野生食材不是緊急軍需；高文明仍可有美食家，但軍圖不會為了美味把它當軍用高價據點。
3. **物種不相容**：帝國居民吃了會中毒、無味、不能代謝或有強烈厭惡；**當地居民或我們的同鄉**可能剛好相反。
4. **戰時評級任務不同**：軍用資料採「可供艦隊修補、加油、取用稀有材料、控制航道」的效益；遊客、餐飲與文化市場是不同維度。

「前老闆討厭巧克力、測繪署把它列毒沼」保留為**少量搞笑個案**；其餘地圖應有可讀的科學測量、同物種毒理或軍政利益依據。帝國並非無能，也不是刻意造假每張圖。

## 2｜《美食獵人 TORIKO》可借鑑的創作方法【一手資料核查】

《トリコ》（島袋光年）是一部以狩獵奇異食材、與廚師合作、探索危險世界為核心的漫畫。VIZ 官方介紹列出美食屋探險與凶猛食材生物；東映動畫官方故事有全身霜降肉的野獸、長出海鮮的樹和酒泉。這證明其**作品表現方式是把食物、生物、生態危險與取得方法結合**，不是「星球皮膚塗上巧克力色」就叫美食世界。

**採用其抽象設計方法，而非複製內容：**

- 食材有**生長／繁殖生態**；甜度、香氣、質地由生理及季節形成。
- 食物有**生存與採集條件**：地形、天候、掠食者、時節、處理方法。
- 玩家先**調查與理解**，再取得實用或情感回報，不一定要與怪獸交戰。
- **不同物種的美味標準**可能衝突；同一片植物可對一族食用、對另一族禁觸。
- **可食不等於免費**：法律、當地所有權、生態補充速度、採樣範圍與貿易競爭仍可能存在。
- 可產生「原本只值普通補給的星球，對某些買家卻是豪華觀光世界」的動態價值差，但**不重寫原本不存在的高能礦物**。

**不照搬第三方 IP**：不複製《美食獵人》的食材專名、獨特造型、捕獲等級、角色、料理菜單與劇情；此處為 Odysstra 自創可選素材。科學上目前不存在被證實可直接食用的外星巧克力湖；下列創意一律是虛構世界觀提案。

## 3｜原創美食生態候選：G01–G24＋飲料型 G25–G28（共 28 種）

> **【內容庫 G01–G24】** 這些可能是**低價值普通星系內的一顆行星、一小塊生態區、衛星或季節性生態現象**，不是 24 個新地標。並非每個候選都能讓我方直接食用：最後四個刻意測試「別的物種很愛，我方可能有毒」。所有營養、毒理與產率尚無定量驗證；安全須針對本軍團的生化條件檢測。

**分布與數量不定案**：大多數普通星系仍應貧瘠、安靜，不能每跳一個糖果世界。G01–G28（原本 24 種，後續新增 4 種飲料生態）是「風味／生態機制池」而不是地標名單、固定 28 星系、強制 28 個任務。某些候選可組合在同一顆生命星上形成分帶，部分甚至每局都不出現。**物理資源富礦一旦存在，該星系仍應按實際戰略價值評定，不因食物生態可愛就降級。**

## 4｜低價值軍圖的「重新鑑價」玩法【提案】

**低成本迴圈**：舊軍圖寫「非軍用生物區／異味毒沼」→ 玩家決定是否停靠 → 感測器掃描並確認**本族**能否食用 → 得到新紀錄與少量可用原料／貿易線索／旅程故事 → 自由決定停留或離開。探索成功不要求新的料理樹、士氣倒數或 NPC 個人模擬。

| 資料欄位建議 | 說明 |
|---|---|
| military_industrial_value_prewar | 帝國基於共通物理、軍工、交通及當年經濟給出的價值，保持歷史固定 |
| mineral_energy_assessment | 可用礦物與能源儲量、提取成本、觀測可信度；不因我方嗜甜而改寫 |
| species_assessment_id | 毒理／味覺評分明確指向哪種已知物種，不以「所有生物」取代 |
| biosphere_profile / biomes | 植物、動物、微生物、食物網、氣候、風味形成路徑 |
| edible_zone / handling | 哪片區域、何種成分、需要哪些安全處理；未知不是可食 |
| intel_source / observed_at | 前帝國原始報告與玩家新取樣兩筆紀錄並存 |
| local_rights / sustainability | 當地居民、保育／所有權、可再生採收條件，不等於一鍵全星採空 |
| yield / event_flags | 【待平衡】採集資源、貿易結果、一次性事件旗標，避免讀檔刷食材 |

**價值不會憑空產生**：同一星系可能戰前工業低價、今天因新貿易需求成為高價食材出口港，這是**市場、資訊與政局變動**，不是物理定律突然失效。反之若原本就有高能晶體富礦，帝國應早已標高價並有合理戰略反應。

### 物理／生物學驗證，避免「太空水龍頭一打開就是手搖飲」

1. **珍珠的口感**：現實珍珠主要靠澱粉吸水受熱糊化；所以天然珍珠形態可由生物胞囊／果實提供，但要有生物製膠或溫泉熱處理的合理假設。源：[Scientific American｜Make Boba for Bubble Tea](https://www.scientificamerican.com/article/make-boba-for-bubble-tea/)；[香港浸會大學｜珍珠奶茶化學](https://chem.hkbu.edu.hk/dailylife/bubble_tea)。
2. **咖啡與茶**：能有香氣不代表天然湖泊就等於烘焙咖啡或加工紅茶；加熱、氧化、萃取、脂質穩定性及酸度是不同過程。地熱與共生菌可作世界觀原因，但具體行星是【科幻想像】。
3. **氣泡泉**：用局部天然 CO₂ 釋氣／地層碳酸泉作物理起點；不要宣稱所有星球的海洋必然充滿可長期保存的氣泡。高 CO₂ 的通風安全與飲料食品安全也要分別考慮。
4. **商品原創**：使用者口頭靈感「可樂」「雪碧」「麥香紅茶」是生活飲料比喻，**正式遊戲內名稱、標誌、外觀、包裝與文案均使用本作創造的「雙泉氣泡」「焙穗茶霧」等原創稱呼**，不照搬可口可樂／雪碧或統一麥香的品牌識別。統一企業集團官方產品頁證明「麥香」是現行商業品牌：https://www.pecos.com.tw/brands-%E9%BA%A5%E9%A6%99.html。
5. **不是營養取代品**：可飲性和單一香味成分不代表能餵飽十萬名同鄉；列印器與抽象原料後勤仍是既有規則。
