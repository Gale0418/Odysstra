# W07｜模組化武器藍圖與艦隊配裝：Beyond Kronos 的受控移植

> **狀態：【使用者授權借用方向／Odysstra 對接提案】。** 2026-11-16，使用者指定參考自己的 Beyond Kronos 武器組合。本章以概念重寫，不公開來源私人倉庫的整份文件，也不更動該專案。新增的是設計候選，不是已實作武器、已拍板科技節點或首版開發承諾。
>
> 來源快照：Beyond Kronos `d345eccbf5885f0bd706b8a81d36c65a4a5c55bd`。主要參考 `modular-weapon-system.md`、`projectile-modifier-research.md`、`status-and-area-control.md`、`combat-physics-and-turrets.md`、`defense-doctrine.md`、`player-ship-hulls-and-fitting.md`；僅借其武器、配裝與指揮設計。來源中的 CANON 是**來源專案的決策**，不能自動升格成本作 CANON。

## 1｜三層各司其職，不新增第七門基礎科技

| 層 | 回答什麼問題 | 本作定位 |
|---|---|---|
| 科研／來源 | 我能製造、理解與維護什麼？ | 材料→實彈＋裝甲；能量→射線＋護盾；自律→導彈＋點防。維持三門共用科技，可偏科 |
| 武器藍圖 Blueprint | 這把武器發射後**怎麼運作**？ | 發射器、投送、彈頭、觸發與行為組合；不另造一套互斥職業表 |
| 艦體／配裝／學說 Doctrine | 誰裝它、如何供能、何時打誰？ | 平台負擔、插槽、編隊目標與撤退規則；方便百艦批次管理 |

**神級規則不是普通修飾器。** [W04](warfare-rule-modules.md) 的存在抹殺、直死或萬象修改，不因這套組合語言而變成「每枚分裂子彈免費附帶抹殺」；背景存在、玩家准入、實際處理規則須分開。

這套語言能讓玩家想「分裂塞進追蹤魚雷會怎樣」，而不只看 DPS 多 5%。但它不要求完整 Noita 式無限遞迴，也不要求玩家逐艘編寫程式。

## 2｜一份藍圖的閱讀順序

```text
平台 Mount
→ 發射器 Emitter / Launcher
→ 投送階段 Delivery + Guidance
→ 戰鬥部 Payload
→ 觸發條件 Trigger
→ 後續行為 Modifier / Child stage
→ 狀態或區域 Status / Zone（可選）
```

這是**編輯介面的解釋順序**，不是每發攻擊都必須依次產生七個物件；光束可以沒有宏觀彈體，普通砲彈也不必有區域。

| 部分 | 可借的組合方向 | 必須看見的代價／限制 |
|---|---|---|
| Mount | 大小、重量、射界、轉向、承受後座、模組數 | 功率、散熱、結構、射界等具體資料仍待測；不能靠插小船放大成要塞炮 |
| 發射器 | 電磁投射、導彈架、脈衝／持續光束、近防發射器 | 同彈頭可由不同平台投送，分類不看武器名字 |
| 投送／導引 | 高速直射、重型低速、自推進、終端追蹤、標定 | 起飛前算提前量與飛行中主動轉向不是一回事 |
| 戰鬥部 | 侵徹、碎片、熱／輻射、爆破、標記、場效應 | 物理傷害與規則事件分開；射程不因名字好聽而無限 |
| 觸發 | 命中、穿透後、接近、定時、失鎖 | 每種觸發須有生命週期，不能對同一碰撞反覆領收益 |
| 行為 | 齊射、散射、有限分裂、再尋標、貫穿、連鎖 | 能量／彈量／子彈數／重複命中／計算預算 |
| 區域 | 碎片帶、短時干擾雲、雷／崗哨帶、維持中的場 | 來源、持續、衰減、友軍走廊、能否繞開或拆除 |

真正的可用欄位與插槽數量由 UI 原型裁定，表中不是全部必做。研究一門學科也不等於免費取得它所有藍圖。

## 3｜投送分類契約：每一段都要誠實

這是移植時最重要的衝突修正。沿用 [W01](warfare-weapons.md)，不要用詞彙漏洞迴避 [W02](warfare-defenses.md) 的點防規則。

| 組合 | 分類與解析提案 |
|---|---|
| 無自推進砲彈＋核／反物質戰鬥部 | 仍是實彈；彈頭會爆炸不使它自動變導彈 |
| 砲彈定時散成無推進碎片 | 父、子均為物質彈體；碎片模式有自己的威脅參數，不獲得免費完美命中 |
| 軌道炮發射母彈，再釋放帶推進器的追蹤子彈 | 母段實彈；子段**導彈**，進點防流程，不能繼承母段的反導豁免 |
| 導彈加高速初段，之後關閉引擎滑行 | 仍是導彈載具的一個飛行狀態；不能關引擎一幀就取消點防已建立的目標 |
| 射線＋掃射／脈衝／多束 | 仍是射線；增加指向與功率分配，不生成能被 PD 擊落的假魚雷 |
| 射線想「命中後分裂追蹤」 | 需要重新定義為光路分配／中繼裝置或其他明示科幻機制；不能自動生出實體導彈 |
| 外場修正無推進砲彈 | 是跨系候選，須說明外場來源、時效、反制；不能靠填 `homing=true` 偷渡 |

**回收與敵我共用：** 玩家、海盜、軍閥、一般巡邏隊讀相同武器語義。差異來自科技、配裝、數量與學說，不是同一枚導彈在玩家手上能被攔、在敵人手上突然免疫。特殊遠古例外須有獨立標籤和玩家可讀資訊。

## 4｜八個可玩的配方候選

全部是【內容庫／待平衡】，不是八項必做任務，也不是正式傷害數值。

| ID／配方 | 組合與畫面 | 作戰角色 | 代價與有效反制 |
|---|---|---|---|
| BP-01 穿線爆破炮 | 電磁實彈＋高精度＋有限貫穿＋穿透後小型爆破 | 打密集直線與大型艦；穿過後爆，不是每幀再爆一次 | 炮塔轉向、射擊窗口、彈藥；疏散編隊、機動或裝甲應對 |
| BP-02 獵群蜂巢 | 母導彈＋接近分裂＋子彈短程追蹤＋小範圍戰鬥部 | 可見的蜂群轉向，對分散小艦形成壓力 | 有限子彈與總載荷；外圈點防先打母彈、末端再攔子彈 |
| BP-03 標定重魚雷 | 重型自推進載具＋資料鏈標定＋終端機動＋侵徹戰鬥部 | 打大型慢速高價值目標 | 庫存與補充工時、轉向上限；截斷火控資料、攔截或提前避開 |
| BP-04 近距霰彈牆 | 實彈＋齊射／散射＋定時破片 | 封近距通道、對付貼身小目標 | 彈藥和覆蓋分散；遠程交戰／避開火力扇面，不保證對重甲有效 |
| BP-05 掃掠脈衝束 | 射線＋脈衝＋有限扇面掃射＋目標輪替 | 反小型威脅或壓制曝光模組 | 同時分功率、熱與指向時間；護盾、遮蔽與跨射界機動 |
| BP-06 誘餌護航齊射 | 主導彈＋有限假目標載具＋協同抵達 | 消耗敵方火控分配，為重彈創造窗口 | 假目標有成本與可識別特徵；更好辨識／分層攔截，不得永久愚弄全圖監視 |
| BP-07 撤退崗哨廊 | 投放載具＋定時展開短命點防節點＋指定護航區 | 讓後勤與旗艦沿走廊撤離 | 節點彈量、壽命、部署時間；可掃清、繞行或遠拆 |
| BP-08 工程碎片屏 | 工程發射器＋有限散佈微粒／誘餌＋短時區域 | 干擾局部火控、增加接戰選擇 | 自備物料、擴散和時效、也妨礙己方；不取消戰勝國對艦隊的大尺度監視 |

**先試的版本**：BP-01、BP-02、BP-05，加既有普通點防即可呈現三種投送差異；BP-07/08 可等基礎行為成立再做。原型選擇可調，不能為了湊八個而推遲第一次試玩。

## 5｜連鎖事件要有「一發」的定義

【工程提案】每次開火給唯一 `attack_root_id`，每個父子段保留 `stage_id`、父 ID、交戰類別、目標與資源來源。觸發圖先限制為有界且無循環；不能讓爆炸的 on-hit 再完整生成自己。

- **同一命中事件只處理一次**：命中、穿透、近炸、摧毀等是不同事件，不可全都無條件生同一批子彈。
- **命中／攔截競爭**：依固定模擬時間和明示優先序處理。母彈在分裂前被摧毀，不能照常生出完整子群；已脫離的子段則是獨立威脅。
- **貫穿／連鎖有目標記錄**：同一次穿越不能因碰撞每幀報告而多扣血；允許回打同目標與否必須有清楚上限。
- **分裂分配預算**：父彈載荷、質量／能量與每個子段成本要記帳。可刻意提供特殊增幅科技，但不是每多一子彈就免費複製完整威力。
- **範圍效果不是額外倍乘器**：破片命中＋爆炸可共存，但同一受害者如何合併事件須定義；UI 要顯示可能事件數，不用單一理想 DPS 遮掩。
- **資源和存檔**：已發射載具、剩餘追蹤燃料、觸發進度和傷害已結算標記都要可保存；讀檔不重生已用子彈。

若未來測「每次只扣 1HP」與多段攻擊，必須額外決定它按根攻擊、每束、每次命中還是其他規則計數。這是 W04 神級交互未決，不讓普通分裂模組先偷定答案。

## 6｜百艦效能與配方試射

【提案】每根攻擊有最大代數、子事件與有效期；每種藍圖有同時運作的預算。所有限制在裝配／試射介面可見，玩家與 NPC 適用同一規則。上限的數字待量測，不能先承諾百艦加分裂仍穩定 60 FPS。

畫面粒子可以簡化，但真實攔截機會、傷害與旗艦生存不能隨畫質、畫面外／內或效能下降而變動。**不能因全局物件滿了就靜默刪掉敵方魚雷，或只刪玩家的子彈。** 優先限制合法藍圖的最壞成本；如需佇列／聚合解析，必須一致、可測且不抹掉點防的窗口。

試射面板至少解釋：起始彈數、最大子段數、分類變化、觸發順序、預計載荷分配、轉向／射界、補給成本與最壞活動事件數。用短流程圖或文字預覽就夠，不必先做 CAD 或全功能腳本編輯器。

## 7｜艦隊學說讓一百艘船不用配一百次

【提案】把 `艦型 + fitting + 藍圖版本 + 任務優先級 + 撤退條件` 存成可套用的編隊配置。不同船體的 Mount 只決定能不能承擔配方，不硬鎖唯一職業。

批次套用前先檢查相容艦、缺件、原料、工時、載員與後勤影響；玩家確認後才在合法整備條件下執行。不因保存藍圖就免費換裝全軍，也不在編輯模板時立刻改掉已出航艦船。藍圖有版本，舊版艦保留原配置直到改裝完成。

重砲射界、慢轉向與近距死角可由機動護衛／PD 補足；偵察標定改善局部射擊解算，但不把「敵國知道艦隊在哪」直接等同每門炮已得到永遠完美的命中解。

## 8｜不從土星搬來的設定

| Beyond Kronos 原場景 | Odysstra 的處理 |
|---|---|
| 大氣阻力、深度壓力、流體魚雷 | 不作全部真空星系的通用規則；有特定介質的遭遇另行標示 |
| CSG 雲凝固、風搬運區域、壓力殼內灌 | 不移植其專屬科技／深潛失敗條件；可另創原創場裝置，但目前非必做 |
| 玩家駕駛小船離開下墜母艦、四船體、十深度層 | 不移植；本作仍是返鄉軍團，戰鬥操作尚未定案、可以回頭 |
| 來源偏好完整模組組合 | 本作先測有限語法；不要求 46 種歷史武器逐一配置完整遞迴 |
| 土星中的火、電、壓力波 | 不把缺少介質的真空畫成大氣火海；有反應物／場維持者要明示來源與代價 |

借的是**可組合的行為與群組指揮**，不是把兩個坑合併成更大的坑。

## 9｜新增驗收案例（全部 Not run）

以下是文案化案例，沒有可執行遊戲測試。命名 `WB`，不覆蓋既有 QA 或 WD。

| ID | 情境 | 預期觀察 |
|---|---|---|
| WB-01 | 同核戰鬥部分別用炮射與自推進投送 | 類別由投送決定，不由 nuclear 標籤決定 |
| WB-02 | 實彈母段釋放追蹤自推進子段 | 子段進導彈／PD 流程，分類轉換可讀 |
| WB-03 | 母彈在分裂前被攔截 | 不產生尚未釋放子群，不重複扣傷害 |
| WB-04 | 貫穿體停留在同一碰撞體數幀 | 不把每幀重複當新命中；有限多段依明確規則計 |
| WB-05 | 爆炸、分裂與近炸互相觸發 | 編輯器拒絕無限循環，合法配方有有限最壞事件數 |
| WB-06 | 分裂前後比較載荷／成本 | 不免費倍增全額父威力，支出和例外增幅可追蹤 |
| WB-07 | 相同快照分別開高／低特效 | 戰果、PD 機會及旗艦狀態一致 |
| WB-08 | 100 艘合法配方同場壓測 | 量測事件量和耗時；不能以靜默刪威脅假裝達標 |
| WB-09 | 批次套用配方到相容／不相容船體 | 先預覽、只合法改裝、材料及工時只結算一次 |
| WB-10 | 子彈已分裂時存讀檔 | 已用資源與既有子段不複製，後續事件保持一致 |
| WB-11 | 真空區域套用氣膠／流場模板 | 拒絕缺乏介質／設備來源的效果；不偷取消全圖監視 |
| WB-12 | 射線藍圖加入導彈專用追蹤／分裂 | 非法組合有清楚原因；需另定機制的候選不自動變成可攔導彈 |

## 10｜尚待採納與下一個驗證

仍待決：玩家是否能編輯完整七段、模組取得／研究方式、Mount 槽位、換裝地點、友軍誤傷、區域種類、觸發上限、PD 的實體／聚合方式、哪些配方進原型。**本次授權的是借用方向，不是預先採納全部解法。**

優先在既有 P-001 增加一個可試射的有限藍圖編輯器，再比較固定武器與組合武器是否讓玩家真正改變選路、編隊與補給。若只增加選單時間卻沒有新策略，縮小語法，不用再加第九種神級模組補救。
