# 04｜遠征軍團、開局編制、人口與旗艦

## 固定的軍團幻想【已確認】

- 初始軍團大約 **10 萬名同一母星出生的同鄉、百艘左右／百餘艘星艦**。這是作品的標準規模感，不代表每次起始數量必須完全相同。
- **玩家可以微調開局艦種與配船。** 讓艦隊戰鬥力、居住／載貨容量與被戰勝國注意的程度互相制衡。
- **若少選載人的後勤／居住艦，開局實際人口就減少**，而不是憑空把十萬人塞進護衛艦。
- 初始軍團是組織完整、厭戰但有戰鬥經驗的軍隊；不能沒有理由地改寫成全艦殘血且連海盜也打不過。
- 長壽／飛昇背景讓自然老死不是主要壓力。損失人口應由戰鬥、事故、撤離、人口調度等可追蹤結果決定。
- **旗艦上有玩家；旗艦被擊沉＝Game Over**。換旗艦、脫離危險區、保險／重開細則尚未決定。
- **10 萬人以數字或少量分群狀態顯示，不逐人模擬姓名與人生。**

## 艦種／功能建議【提案】

| 類型 | 在艦隊中的價值 | 風險或取捨 |
|---|---|---|
| 旗艦／指揮艦 | 玩家所在的戰略中樞、旗艦身份 | 沉沒即敗；不能讓 AI 亂衝 |
| 戰列艦／戰鬥巡洋艦 | 威懾海盜、主要火力與艦隊硬骨頭 | 補給、戰術暴露、整備成本 |
| 巡洋艦／驅逐艦／護衛艦 | 護航、截擊、偵察、機動分遣 | 面對遠古重裝部隊很脆弱 |
| 運輸／居住艦 | 容納軍團人口、物資與隨軍裝備 | 降低戰鬥艦配比；需護航 |
| 維修／工程艦 | 修復艦體、改裝與回收 | 需要技術人力與材料 |
| 工業／採礦艦 | 野外補給、礦料與造船支援 | 移動較慢，佔用編制與貨艙 |
| 燃料採集／補給艦 | 恆星採集、跨星域補給 | 需要保護、時間與貨艙 |
| 高階泰坦（特殊候選） | 局部極強的古代戰略資產 | 戰勝國戰略關注、稀有零件、艦隊速度 |

**不預設所有艦種都必需或總量。** 艦船數值與科技層級必須由戰鬥原型驗證。

## 開局配置的正確取捨

不要只計算「軍力點數」；建議至少檢查：

1. **總編制預算**（高級艦更昂貴）。
2. **可容納人口**（不夠就縮減開局軍團人數；不要憑空生成船艙）。
3. **燃料／貨艙／維修能力**（越大艦隊後勤負擔越明顯）。
4. **戰勝國注意力**（高階戰艦與戰略遺產比普通護衛艦更可疑）。
5. **部署與指揮容量**（百艘軍艦能擁有，但不一定同場微操）。

**【提案】** 預設開局「均衡遠征軍」「重型作戰群」「工業護航群」「攜戰損泰坦的高風險開局」，再提供自由微調。但預設模板、價格、泰坦是否真的能在新手難度選用均未拍板。

## 關注度 vs 雷達特徵 vs 威脅評估

- **雷達特徵**：艦隊多容易被附近敵人感測到（傳感、艦體大小、引擎）。
- **戰略關注**：戰勝國是否認為你值得派重兵處理（泰坦、對接管區開戰、古代遺產等）。
- **處理優先度**：在全銀河同時出現多個威脅時，你在戰勝方行動佇列排第幾。
- 使用哨兵陣列的戰勝國可能已知玩家位置，仍可能因距離、任務價值、兵力調度而不追。不要把「不值得追」寫成「它看不見」。

## 分遣與百艦呈現【方向】

玩家應能讓偵察小隊、工程／採礦分艦隊與主力隊暫時分開工作；但**跨星域分遣 AI、戰鬥時預備隊如何上場仍是待決題**。

**推薦初版介面：** 100 艘船都在資料模型中；分為戰鬥群、護衛群、工業後勤群、偵察分遣群，UI 用群組面板與篩選，避免一頁 100 張同尺寸艦船卡。戰場採少量可見編隊或部署限制，細節見 [06](06-combat-and-command.md)。

## 人口模型【已確認／待決】

- 顯示「軍團現有人口、初始同鄉人口、艦隊載員容量、必要操作人員、傷亡」等聚合值，足以支持返鄉結算。
- 初始人員主要是軍人與軍事後勤人員；可有醫療、工程、行政支援，但不要自動新增大量隨軍平民或兒童群體。
- 新加入的外星雇員可否算進「返鄉同鄉人數」？**待決**；至少應把「原生同鄉」與「後來加入的人」分開結算，不要混同。
- 旗艦一次擊毀不等於全十萬人死亡；但玩家作為司令死亡＝本輪 Game Over。結算與存檔處理待設計。

## 平衡測試問題

- 玩家不選居住艦，人口是否合理下降而不使艦隊失去操作人力？
- 高級艦是否真的有局部作戰優勢，不是純負面「招惹戰勝國」？
- 純低配艦隊是否能靠機動、低成本、自由航線成功返鄉？
- 人口隨傷亡、援軍和分遣隊變動是否一致且可追溯？
- 玩家旗艦是否能透過編隊定位、先兆警報、撤退機制避免無預警死亡？
