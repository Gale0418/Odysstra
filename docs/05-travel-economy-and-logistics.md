# 05｜自由航行、原料、燃料、貿易、搶劫與造船

## 請先把馬鈴薯放下【已確認】

本作的飛昇種族星艦具有高度自動化設備與**萬能食物列印機**。不要做每餐種菜、偷菜、醫院排班或大量日用品的細碎管理。

**【已確認】**
- 食物與部分消耗品以概念上的**原料**表示。
- 補給包可以向太空站購買，類似《遠行星號》。
- **燃料可以購買，也可以在恆星旁採集／吸收。**
- 資源可以來自採礦、打撈、貿易、軍港、戰利品，**搶劫也是玩家可選的辦法**。
- 玩家可以花時間維修、造船、殖民或建立基地，不能為了催回家而禁止擴張。
- 世界時間仍然在走，戰勝國接管與其他勢力會繼續發展。

**【待決】** 「原料」要不要再拆成「艦船整備零件／造船工業材料」是系統平衡問題；不應在沒有測試前擅自設成二十種礦石。

## 推薦的最小資源介面【提案】

| 資源 | 用途 | 取得 |
|---|---|---|
| 原料／通用補給 | 食物列印、消耗品、基礎維持 | 太空站補給包、貿易、礦料處理、打撈 |
| 燃料 | 移動、躍遷及採集設備運作 | 購買、恆星採集、奪取、補給站 |
| 工業材料（可延後） | 大型維修、改裝、建造星艦 | 礦區、拆船、船塢貿易、回收 |
| 貨幣／交換價值（可延後） | 買賣艦船、設備與通行服務 | 交易、傭兵合約、出售資產 |

十萬人的人力狀態不是獨立「食物計時器」，而是艦船維運與產業作業的能力限制。所有日消耗、採集速率、售價、艦船維修成本**待原型數值平衡**。

## 燃料吸太陽，不等於遊戲失去策略

**【設計張力】** 可以在恆星邊採能源，但不能設定為「一鍵瞬間無限加油＋無時間成本」，否則太空站補給、搶奪油船與航路規劃全部失去意義。

可測試的成本（僅候選）：採集需要時間／設備；部分恆星不適合高速安全採集；十萬人百艦一起補給需要更長時間；採集時位置相對可預測；高純度躍遷物質可能另有處理或採購需求。這些不是全部要加，只挑最能讓玩家做決策的。

關鍵：**補給本身不是折磨，花時間補給會讓戰後銀河繼續變化。**

## 一次典型航程【提案】

1. 在舊星圖挑航線；查看歷史補給點與已知現況情報。
2. 決定帶主力或派偵察分隊先行，必要時調整艦隊編組。
3. 航行消耗燃料；途中可能遇到殘骸、敵方巡邏或交通阻塞。
4. 抵達星系後，觀測實際政府／資源／航門狀態；更新情報時間戳。
5. 決定停靠交易、採礦、修船、攻擊、搶劫、協助友軍，或者不做事直接離開。
6. 資源、艦船、人口與勢力關係依實際行動改變；世界模擬向前。
7. 往下一個星系，或自由回頭。

**不是每一跳都強制彈出三選一道德題。**

## 經濟與海盜行為

- 商業旺盛的交通樞紐有大量交易需求；周邊無人小行星帶可能形成海盜埋伏區。
- 百艘正規軍可以嚇跑弱海盜，但孤立分遣隊可能成為好目標。
- 玩家可以搶海盜、軍閥、商隊或補給站；被搶者、商人、當地政權和戰勝國可能調整關係、價格與關注。
- 不把搶劫設計成善惡選項，而是實際行動及後果。
- 工業據點有產能、材料、船塢條件；**占領船塢不等於立即得到無限泰坦**。

## 採礦／造船／修船

- 玩家能在無人資源地採礦、在可用工業設施修船或新造艦艇。
- 新造的艦艇不必自動屬於母星同鄉；必須有操作人力、船艙容量與維持能力。
- 可以在沿途留下工業基地或維修站，分遣隊可能回頭利用。
- 產能與造船時間初期採簡化，後期才視需要增加配方與造船廠等級。
- 打撈前宗主國資產可以帶來性能優勢，也可能帶來高關注與維修困難。

## 防止無聊與無限資源

- 測試「只挖礦」能否無成本造出無敵艦隊；若可以，優先調時間／物流／產能的取捨，不先用硬禁止。
- 測試「不挖礦」能否透過貿易與回收合理返鄉；不能逼每個玩家當礦工。
- 測試「100 艘開局」是否被日常消耗壓垮；不應在沒有戰鬥的情況下被補給機制逼得反覆讀檔。
- 檢查一般低價值星系是否真的能讓玩家喘口氣，而非每跳都發生核武事件。
