## 一、先決定生成單位，不是「一種口味 = 一顆星球」

**【使用者最新方向】** 想把炸雞、牛排與所列鹹香、奶香、肉類、夜市、海味、酸辣、甜點及獵奇風味**都放入低機率隨機遭遇庫**；出現機率稀少，而不是把每顆普通星系硬改成美食大賣場。詳細權重／事件上限仍【待平衡】，不能把某個假定百分比宣布成使用者定案。

建議組合語法：

~~~text
候選正常星系／行星／漂遊生態區
  + 生物結構（藻、菌、種子、脂質、礦化甲殼、巨獸脫落物）
  + 風味標籤（FL-001…FL-097，可選一個主味及少量副味）
  + 自然加工條件（地熱、發酵、乾燥、壓力、成熟期、後勤料理）
  + 物種相容性（本軍團／帝國物種／當地住民，分開判斷）
  + 採集方式與可持續性
  + 舊軍圖評級／現時情報／可選事件
= 一次具獨特外觀與行動選擇的美食發現
~~~

不保證所有 97 個條目每局都會出現；也不需要 97 顆專門地標，更不需要做 97 種 3D 生物。**97 是素材資料行數，不是開發數量承諾或已完成遊戲功能。**

## 三、從 97 個名字收斂成七組可程式化感官軸【提案】

| 軸 | 風味的遊戲內來源 | 可能的陷阱 |
|---|---|---|
| **鹽與礦質** | 生物相容鹽晶、海藻礦質、地熱調味層 | 鹽濃度太高；珍貴礦物不一定能吃 |
| **糖、酸與果香** | 光合儲能、果實、花蜜、發酵有機酸 | 果香分子不代表無毒；酸蝕與病原 |
| **乳脂、堅果與油香** | 高脂種子、脂質囊、乳化型菌膜 | 脂質氧化、過敏原／消化相容性 |
| **蛋白、鮮味與肉感** | 胺基酸、核苷酸、纖維化生物組織 | 「像牛排」通常需成熟、加熱與多成分調味，不是生切一塊肉就完全相同 |
| **焙烤、焦糖與煙香** | 地熱、氧化、控制性烘乾／料理 | **真空本身不會自動炸雞**；加熱、反應物、溶劑及條件要有交代 |
| **辛香、冷感與刺激** | 化學受體作用、辛香揮發物、生物防禦分泌 | 物種差異很大；辣與毒是不同軸 |
| **發酵與特殊氣味** | 菌群代謝、含硫物、胺與脂肪酸 | 喜好兩極化；不因當地居民在吃就確定適合我方 |

**配方交互不強迫玩家管理每個分子。** 可以先保存資料供事件敘事，第一個實際原型仍用抽象原料／風味描述與少量清晰的安全檢測條件。風味不是 D​​PS，不必幫每個條目做數值加成。

## 四、兩個可用的資料契約【提案／非實作程式】

**FlavorProfile：**
- flavor_id：FL-001…FL-097；source_name 只存歷史靈感標籤，game_display_name 可另命原創名稱。
- sensory_axes：鹽／甜／酸／苦／鮮／脂香／焙烤／刺激／發酵，非實驗室真實數值。
- generation_bases：適合的「生態生產者／加工」標籤與相容條件；沒有符合條件便不生成該風味。
- preparation_required：直接安全採樣、需熱處理、需發酵、需提純或不得食用；依**目標物種**決定。
- audience_species_id：不能把帝國厭惡的口味和本族可食性混為一談。
- rights_and_claims：不能因風味名稱涉及現實品牌就把那個品牌當成 Odysstra 遊戲內商品。

**GourmetEncounter：**
- candidate_id、world_seed、system_id、body_id／organism_id、flavor_profile_ids、discovery_state。
- prewar_military_value 與 known_mineral_value 由共通物理／戰前條件決定；**高能晶體或珍稀礦物富礦不能因為味道好吃就強行變低價**。
- life_signs_known、species_safety_assessment、scan_time、harvested_amount、regrowth／migration、claimed_owner、resolved_event_id 必須可持久化。
- 同一存檔重進不刷新獨特美食／巨獸；玩家不採樣可純路過；內容庫不應變成強制美食主線。

## 五、不是所有口味都一定能在野外天然長好

- **牛排、炸雞、鹹酥雞、滷肉飯、麻辣鍋**是複合料理風味。可以讓某種外星生物產生合適脂質與香氣，再由後勤處理後呈現相似感官；不宣稱整隻野獸已自然油炸。
- **奶油／起司／蜂蜜／海鮮**可由非地球來源的相似代謝物形成類比，但不表示天然長出了乳牛、蜂群、龍蝦和食品衛生標章。
- **飲料**需區分天然液體、真實氣泡水、香氣、乳化層與微生物安全；珍珠奶茶相關地貌仍看 WORLD-02 G25–G28。
- **惡臭或獵奇類**適合用「別族喜歡、我們可能不耐」的角色互動。對外星物種的可食性是待證，不是全宇宙通用的『毒／美味』判斷。
- **食品資料不是毒性指示書**：未檢測物體不直接食用，某些事件以交易、文化研究或掃描完成，同樣算有趣。

## 六、科技、版權和來源邊界

**科學基線（有限）：** NASA 探討現有生命的基本需求包含可用能量、液態水與營養；支持需要交代生命維持條件，不支持已發現任何可食外星生態。來源：https://science.nasa.gov/universe/search-for-life/life-on-other-planets-what-is-life-and-what-does-it-need/ 。

使用者提供的 97 條口味是**私人腦洞素材清單**；並未逐一追溯商品、品牌年份或市場地區。此文件不得作為「97 款確實存在的洋芋片 SKU 調查報告」，更不能直接用在商業宣稱。正式遊戲採原創用語、原創巨獸與生態地貌。

## 七｜風味隨時間與環境改變（後續方向）

97 個 FL 名稱只是**可組合風味詞彙**，不是「巨獸天生只能掉一種固定口味」或 97 件已製作素材。最新使用者希望同一隻巨獸**近期日曬變脆、外緣低溫變冰鎮、實際泡過飲料星的液體／霧才可能新增風味**；參見 [WORLD-05](world-05-orbital-marination-and-flavor-state.md) 之條件化狀態。不同部位、季節和加工後的風味、以及物種毒理可不同，並不保證愈曬愈香或愈冷愈安全。
