## 狀態與證據

| 標記 | 意義 |
|---|---|
| 已確認 | 使用者親自決定的背景、意圖或規則；仍須區分背景存在與玩家可用 |
| 歷史設定／指定參考 | 過去創作保留，若後來更正以最新決策為準 |
| 方向／提案／內容庫 | 候選解法、配方、事件與世界素材，不是開發承諾 |
| 待決／測試預設 | 未知保留未知；原型暫定數字不當正式數值 |
| 研究／條件演算 | 原作資料、現行物理與明示假設；不代替本作虛構規則 |
| Not run | 遊戲驗收案例尚未執行；文件 CI 成功不改變它 |
