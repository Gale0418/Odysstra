# COSMO-05｜海洋理想城與氣態天空理想城：概念美術、構圖與天體關係規範

> **性質：【美術參考／內容庫】，不是已完成可交付的遊戲場景、美術原檔或預製模型。** 本章把使用者在連續討論中提出的兩張圖整理為可重畫、可交給美術或圖像模型使用的規格。構圖以華麗、壯觀、色彩清晰為優先，但必須有合理的天體和城市工程邏輯。
>
> **已明確的美術要求**：高空斜俯、看得到天空、科技極高、能看到飛船飛行、有無邊城市、**不可有天然陸地**；海洋版必須同時呈現水上與水下，氣態版必須呈現雲上與雲下。氣態版背景**不應出現另一顆氣態巨星**，可有大型岩質／冰衛星或本行星星環。

## A｜全球海洋理想城（Pelagic Ecumenopolis）

### A1. 主題與鏡頭

- 畫幅：16:9 橫向寬銀幕；高解析概念藝術。
- 機位：從空中約斜 30–60 度俯看，既看得到地平線和天空，也看得到近景街區和海洋內部。
- 天際：海洋與浮動城市一直延伸到遠方。**沒有海灘、島嶼、露出的岩石陸地、沙洲**。
- 三層敘事：最上方晴朗的外星天空和飛船，中間海面的大都市與船港，下方透視剖面呈現海中環形棲地和更深處燈火。
- 主焦點：1 個大型都市核心環；周圍有許多密度不同的模組城市，避免「三棟樓＋四個圓盤」就宣稱全球都市化。
- 尺度錨點：空中大型巡航艦、近景運輸船／港口、微小交通艇、交通光帶；使巨構尺度容易判讀。

### A2. 城市如何合理發展

| 分層 | 功能 | 視覺語言 | 錯誤做法 |
|---|---|---|---|
| 海面上層 | 住宅、學院、商務、星際港 | 浮動街區、大廈、圓環市中心、溫室穹頂 | 畫成孤零零的海上城堡 |
| 海平面交通 | 貨物、旅客、造船與補給 | 橋接都市塊、港灣、船艇、升降月台 | 全世界只靠狹窄玻璃天橋承重 |
| 淺海 | 透水棲地、交通、光合能源與養殖 | 可見的光束、管道、弧形平台、魚群 | 把所有水下生活區畫成完全乾燥的玻璃球 |
| 中深層 | 城市節點、科研、化工與循環處理 | 球狀居住節點、柱狀交通井、逐漸變暗 | 不加距離衰減，任意直視數公里深海 |
| 極深層 | 另有專業設施／特殊研究 | 細小光點、重型耐壓設備 | 如普通住宅街道一樣明亮 |

**光學誠實**：正常海水不可能從地表一眼看穿數十或數百公里。為了讓畫面同時見到上下兩層，可採**藝術剖切視角／半透明截面**；圖註清楚這是一張示意概念畫，而非真實肉眼透視。

### A3. 天文與環境限制

- 星球只有海面，**不能露出陸地**；可有浮式海上建築和港口，但要能看出不是天然島。
- 遠方有一顆恆星作主光源即可。大型岩質衛星可見；如需氣態巨星作背景，應明確設定海洋星球是該巨行星的衛星，才有合理的天體關係，不要莫名擺兩顆同樣巨大的氣態星在旁邊。
- 天空中的星體大小由距離與天體本身尺寸決定；不為了壯觀任意把每顆月亮畫成佔半個天空。
- 海面有波浪、洋流、反射與大氣霧，避免視覺上變成一塊平整玻璃地板。
- 深海建築與大氣／海面空港之間要有**物資上下轉運**，不是只有發光條紋。

## B｜氣態天空理想城（Atmospheric Ecumenopolis）

### B1. 主題與鏡頭

- 高空斜俯，寬廣天空清楚可見，帶有真實的大氣遠近感。
- 畫面 1/3 左右保留天空及天體；中間為明亮雲海上的無邊浮城；雲層破口露出下方另一層暗色、高密度工業城。
- 視覺上必須毫無疑義：**這顆世界沒有可站的固體地面**；沒有海洋、岩石地基、山峰或普通島。
- 近景一艘大型飛行艦帶出尺度，遠景大量小型航空交通；多個造型不同的懸浮城市不必全部是同一種圓盤。
- 上層可以華麗、有綠意與住宅穹頂；下層是採氣、能源和工廠，不要求所有人直接暴露在氫氣中。

### B2. 合理的城市分層

| 區域 | 功能 | 視覺提示 |
|---|---|---|
| 上部低壓光照層 | 住宅、空港、研究、觀景 | 雲海、園區、密閉街區、通行飛船 |
| 中層城市核心 | 主要居住、商業、行政與轉運 | 巨型環形平台、分離的都市群、廣域空中交通 |
| 雲隙之下 | 採氣、化工、工業能源與無人巡修 | 暗金或銅紅照明、機器群、壓力等級分界 |
| 深層危險區 | 高壓／高溫／強風設備 | 渺小遠光點、能源設施、巨大雲帶與風暴 |
| 外層太空港 | 衛星交通／軌道居住延伸 | 上方可見升降航路、遠端運輸艦 |

城市可以用空中交通線、垂直懸浮轉運、近距連接器連成網，但不要畫出「從沒有地面的地方垂下無限長的承重柱直到地面」。如果用纜索或支架，需交代它接的是**另一個浮動節點**，而非看不到的岩盤。

### B3. 天體關係硬限制

**使用者已親自強調：**氣態巨星的天空**不應再有另一顆氣態巨星**。這是本組視覺的**已指定美術限制**。

合理背景候選：
- 一顆極大的**岩質／冰質衛星**，有坑洞或冰面地形；
- 小一點的第二顆衛星，和大衛星的尺度及距離有層級差；
- **本顆氣態巨星自己的星環**沿天空上方或地平線形成傾斜弧線；
- 恆星／星光／薄雲與遠處大氣散射。

**需要注意**：
1. 星環本身與巨星赤道有近似固定的幾何平面，觀察者所在緯度影響顯眼程度。
2. 在環面附近，星環可能只像一條很細的線；偏離環面才可能看到寬大弧帶。
3. 巨衛星能在天空看起來很大，但不宜大得像另一顆主行星，除非世界觀允許極端近距離與潮汐環境。
4. 都市可處於氣態巨星的對流雲上方，不應把「另一顆行星表面」畫在腳下。

### B4. 色彩、層次和鏡頭主體

- **雲上**：清爽藍天、暖金色日光、象牙白雲海與銀白城市。
- **雲中**：較高對比的巨大懸浮環與橋連接、光束導引、空中貨運。
- **雲下**：深藍紫／橘紅工業層、雷暴和能源平台，避免全景漆黑。
- **飛船**：幾艘大型長形高科技飛船＋大量遠處小艇；它們飛在天空中，不是停在固體地面港口。
- **遠方**：都市節點變小、變淡，直到與大氣散射融為一體，建立「無邊都市」而不是靠重複貼圖硬塞。

## C｜兩組共同的繪圖驗收清單

| 檢查項 | 海洋版 | 氣態版 |
|---|---|---|
| 看得到天空與遠方地平線 | 必須 | 必須 |
| 從上方斜俯看城市 | 必須 | 必須 |
| 飛行艦艇有近景大船與遠景交通 | 必須 | 必須 |
| 城市一眼看出不只是小聚落 | 水面＋海下都要無邊 | 雲上＋雲下都要無邊 |
| 不能有自然陸地 | 不得有岩岸／海島 | 不得有岩石／地表 |
| 需要合理功能分層 | 浮島／水柱／深海 | 低壓／中層／危險深層 |
| 需要水平與垂直物流 | 海上船港＋深海轉運 | 壓力層轉運＋空港 |
| 光學不能自相矛盾 | 深水宜用藝術剖切 | 雲底只在雲隙看見 |
| 天體關係 | 請交代衛星／主行星關係 | **不得出現第二顆氣態巨星** |
| 圖像文字 | 不要無謂標語和假字 | 不要標語、偽字、浮水印 |

## D｜不應偷渡到遊戲規格的事

- 這些是**概念畫**，不是承諾做成大型可自由探索 3D 城市地圖。
- 不要求所有海洋星必然數百公里深，也不要求氣態巨星真正每層都可住人。
- 不因畫中有幾十艘飛行戰艦就說本作會在每顆星系渲染那麼多 AI。
- 「巨大衛星＋星環」是氣態都市視覺參考，不表示所有巨行星都必須有非常壯觀的環。
- 本次只把畫面思路寫入文字設計資料庫；**不宣稱概念圖的二進位原圖已附加到 GitHub**。原圖需另走有來源與授權紀錄的資產上傳流程。
