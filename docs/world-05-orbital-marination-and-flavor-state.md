# WORLD-05｜軌道熟成、巨獸環境入味與可持久化風味狀態

> **2026-11-16｜使用者明確題材＋系統提案**：同一隻太空生物可能在近日點曬得嘎嘣脆、在星系邊緣呈冰鎮風味、又去飲料世界泡澡而改變外膜香氣。**方向已由使用者提出，但具體狀態機、名稱、數值與觸發條件尚未定案或實作。** 沿用 [WORLD-04 的 12 種巨獸](world-04-pseudoplanet-gourmet-megafauna.md)、[WORLD-03 的 97 種風味](world-03-galactic-flavor-catalog.md)與 [WORLD-06 的飲料地貌](world-06-beverage-worlds-and-carbonation-physics.md)，不替換它們原有名字或稀有度方向。

## 一、風味不是「物種永久屬性」，而是可變狀態

**生態基底 × 個體與部位 × 曝露史 × 加工條件 × 評估物種**，產生玩家最後辨識的風味。這是**敘事／玩法生成式，不是自然科學正式方程式**。

| 狀態層 | 需要追蹤的因素 | 必須避免的錯誤 |
|---|---|---|
| 本體與部位 | MB 物種、個體 ID、背甲／鰭膜／脫落膠珠 | 同一條魚不同部位也能不同味；不免費複製樣本 |
| 熱／日曬 | 恆星熱通量、停留時間、外膜水分／糖／胺基、內部熱控 | **曬太陽不是自動油炸**；受熱過度可焦化或死亡 |
| 冷卻／外緣 | 輻射散熱、內生熱、冷卻時間、脂水相態 | 遠離恆星不代表瞬間結冰；凍融可能傷口感 |
| 顆粒／香料 | 適合的生態塵、共生微生物與真正的物質接觸 | 真空中不能隔光年直接聞到香味，必須取樣或近場量測 |
| 飲料地貌接觸 | 實際液體、可收集泡沫、氣膠、接觸面與時間 | 同星系不等於已泡澡；香氣不等於毒理安全 |
| 料理與食品安全 | 乾燥、加熱、清洗、發酵、採樣時間 | 類牛排／炸雞多半是**加工後的複合風味**，不是生啃就現成料理 |

### 太陽邊「嘎嘣脆」的前提

對有蛋白／胺基與還原糖樣前驅物的幻想生物，適度加熱／乾燥可在外層造成焙烤樣風味；**梅納反應需要特定反應物、水分、溫度與時間**。接近恆星也可能帶來過熱、強紫外線／輻射損傷與碳化，不能只把距離越近設定成味道越好。科學起點：[American Society of Baking｜Maillard Reaction](https://asbe.org/article/maillard-reaction/)。

冷區改變脂質、膠體和水冰的相態，低溫可形成冰脆／冷藏口感，但不會自動清除毒素或病原；凍融會傷害某些組織。風味必須有**適用於本軍團生理**的採樣評定，舊軍圖的帝國物種資料則獨立保留。

## 二、十二種既有巨獸 × 軌道／飲料接觸候選

| 物種 | 日曬／暖域 | 外緣／冷域 | 真正接觸飲料生態後（都屬提案） |
|---|---|---|---|
| MB01 酥殼日眠魚 | 近日點：乾燥脆皮／加熱過度變焦殼 | 遠星：冷脆脂膜／凍傷風險 | 茶霧、琥珀糖泉附著茶香脆殼 |
| MB02 炙紋牧星鯨 | 暖域：類烤牛排外膜／熱損傷 | 遠星：冷硬纖維、非自動醃製 | 焦糖咖啡地熱霧接觸鰭端，產生咖啡香牛排候選 |
| MB03 奶霧彗尾水母 | 受熱：富脂凝膠濃縮 | 極冷：奶霜狀膠片，可能脆裂 | 花蜜泉帶回甜香物質 |
| MB04 煙環魷鰭獸 | 乾燥膜經後勤烘烤呈烤魷魚香 | 冷乾：薄膜易碎 | 鹽泉礦鹽附著，須去除雜質 |
| MB05 菌冠岩龜 | 過熱：松露香菌膜失活 | 冷季：休眠降低香氣 | 濕潤茶霧促進部分共生菌活動 |
| MB06 金沙晶螯獸 | 受熱：金沙樣脂香或氧化壞味 | 冷卻：脂質凝結，非保證安全 | 泡過鹽泉更鹹，可能過鹹 |
| MB07 滷香砂背獸 | 曬熱脂膜排香 | 冷域：揮發香味降低 | 酸甜泉膜改變表層鹹香 |
| MB08 酸辣電紋蛇 | 高溫：刺激性分泌增多 | 冷域：活動降低 | 酸泉可能腐蝕或改變離子態 |
| MB09 陳釀星囊 | 過熱：發酵菌失活／腐敗 | 冰凍：發酵速度減慢 | 外界菌群接觸可能污染 |
| MB10 糖霞蝶母 | 日曬：翼片乾燥糖化 | 冷域：糖膜析晶 | 果香雨霧可附著熟果氣味 |
| MB11 炭輪飄游獸 | 日照：高熱與焦香表層 | 冷域：硬殼、較低採集窗口 | 氣泡泉冷卻局部外殼 |
| MB12 珠海巨母體 | 高熱：珍珠胞囊損壞 | 低溫：囊膜收縮或凍裂 | 本身與 G25 的液態生態相連，按孢囊成熟度變味 |

以上都是**可能風味走向**，不是保證獎勵；同種個體不同年齡、部位與健康狀態可能不一樣，也可能完全不可食。必要時只留下感測器資料和老兵日誌即可，不強制狩獵。

## 三、體型是最大的宇宙泡澡限制

- **普通大型個體／幼體**：在其體積、密度、生命維持可適應的湖、泉、近岸液海內泡澡。可以拿到類可樂糖膜或茶霧香氣。
- **小衛星量級的偽行星生物**：若具有可觀質量與重力，整隻跳進行星海洋會造成嚴重引力／潮汐／撞擊／海水位移後果，**不能畫成毫無代價的可愛洗澡**。替代方案是外延鰭膜接觸上層雲霧、攝取飄出的微粒／地熱噴流、讓幼體下水、或在外軌道遠觀。
- **真正行星級巨獸**：屬特殊古代生物工程／世界級生命體的強超科幻想像，牠與普通汽泡泉的「洗澡」不在同一尺度。當背景奇觀，不拿一般碰撞判定或游泳動畫處理。
- **出入大氣**：還有引力井、進入速度、空氣動力加熱、浮力、表面壓力和大氣組成。若只需要增加風味，讓部分表膜／附生小體接觸比整隻巨獸入海更便宜、更可信。

**設計喜劇例句：**「MB01 酥殼日眠魚幼體進入 BV03 雙泉氣泡星的琥珀糖泉，外層糖膜出現焦甜香」成立為候選；「200 公里衛星級巨獸直接掉進可樂星，大家只得到一份甜醬炸雞」不應默認成立。

## 四、最小可存檔的風味狀態契約【提案】

~~~text
FlavorState:
  organism_id                 # 世界裡唯一個體，不因重返星系重抽
  segment_id                  # 皮膜、角質、鰭、膠囊等樣本部位
  base_flavor_ids             # WORLD-03 中既有 FL-001...FL-097
  age_or_maturation           # 個體生長階段，未知不填成 0
  thermal_exposure            # 依實際時間與環境更新
  cold_exposure               # 受內生熱與輻射散熱影響
  actual_contact_biome_id     # 有真正接觸才有，非看見星球就給風味
  texture_state               # flexible/crisp/chilled/frozen/charred/decayed
  species_safety_by_id        # 我軍、帝國、當地物種，獨立判定
  sample_id / harvested       # 防止同一片外殼被多次領取
  intel_observed_at / revision
~~~

**時間正確性**：世界時間、個體位置、環境接觸、取樣紀錄須持久化；不能切換畫面、調幀率或讀檔就改變風味，也不能把「炸雞＋咖啡」當成免費多一件道具。焦化與感染可以是負面狀態，冷藏／加熱有可逆與不可逆變化，不是永遠往更高稀有度進化。

## 五、六張可選事件 FC01–FC06

| 事件 | 世界情境 | 玩家行動 |
|---|---|---|
| **FC01｜近日點限時脆皮** | MB01 緩慢進入暖域，外膜從柔韌變乾脆 | 現場掃描／等待安全採樣窗口／直接離開；繼續受熱可能焦化 |
| **FC02｜冰鎮牛排不等於冰塊牛排** | MB02 前往外緣，外層脂水相態轉變 | 比較兩次樣本，查是否仍可安全料理 |
| **FC03｜星鯨的焦糖蒸汽浴** | MB02 在 BV02 上空以小面積附屬構造接觸香霧 | 不讓小衛星質量的身體砸入行星湖 |
| **FC04｜可樂泉的翻車魚幼稚園** | MB01 的幼體在 BV03 局部泉灣玩耍 | 採自然脫膜／研究／繞開，不把幼體整群變免費糧倉 |
| **FC05｜珍珠可能是活卵** | MB12 在 BV01 產生膠珠 | 檢測胞囊是否活性，選安全脫落物或只記錄 |
| **FC06｜香氣消失之謎** | MB09 進入冷區，發酵活動下降 | 分清冷卻、失活與病原污染，不能把難聞＝危險當普遍定律 |

## 六、驗收提案（FS01–FS08，全數 Not run）

FS01 熱／冷變化必須有時間與條件；FS02 同一個體不同部位可異；FS03 沒有接觸便不能附加飲料風味；FS04 衛星級本體不以無代價泡澡處理；FS05 加熱過量可能變壞；FS06 讀檔、重訪不得再生同一樣本；FS07 大型生物反應有預警和撤退；FS08 不參與美食內容仍可正常返鄉。

**不擅自增加遊戲核心系統。** 這是 WORLD-04 美食巨獸偶遇時可選的資料增益；它不是一款替代返鄉沙盒的食物狩獵模擬器。
