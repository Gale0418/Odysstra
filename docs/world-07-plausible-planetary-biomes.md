# WORLD-07｜普通奇景行星：類食物外觀、異星生態與可驗證生成規則

> **2026-11-17｜使用者已確認「除了超稀有的真正美食星球，也要增加更多有可能自然形成的普通星球」，並以「水蜜桃汁海洋」為示例。** 本篇的 **PB01–PB12** 是【原創內容庫／程序生成候選】，不是十二顆新的固定地標、已經存在的實測外星行星、十二套新玩法或實作完成。行星外觀像食物／飲料，**不等於飲用或食用安全**；真正可食世界仍見 [WORLD-01](19-edible-worlds-and-food-planet.md)，奇幻飲料世界見 [WORLD-06](world-06-beverage-worlds-and-carbonation-physics.md)。

**一句話定位**：讓平凡星系也具有符合地球化學、地質、水文、微生物學或有限異星生態假設的景致；不把每個低價值星系都變成美食樂園。

## 一｜已確認方向、限制與科學分層

- **【已確認的創作方向】** 除了稀有「真的能吃」的美食星球，還應有更多**看起來像果汁、奶昔、茶湯、冰沙**等，但可用自然機理解釋的普通行星。外觀、氣味是探索樂趣，不是保證食物來源。
- **【已確認的作品基線】** 沒有特殊價值的普通星系仍大量存在；高能晶體、戰略礦物與軍事設施的客觀價值仍由軍圖如實評估。不同物種的安全性與味覺**不能混成同一個等級**。不修改既定返鄉主線、抽象原料與燃料後勤。
- **【研究與假設】** 地球上確有粉紅鹽湖、含色有機水、乳白冰川湖、局部含氣湖、夜光海域、含鐵水與冰凍碳氫海等機理；但**全球均勻桃香海、藍莓色外星藻海**尚無實際觀測，是以現有機制加上虛構外星生態的推演。

| 科學標記 | 解讀 | 生成規則 |
|---|---|---|
| **N1：地球已有局部類比** | 一定條件下，真實地球環境可出現類似顏色或地貌；不保證全球覆蓋 | 可成為普通行星的局部區域／季節狀態 |
| **N2：地球機理＋假想外星生命** | 物理化學成立，但需另外假定異星微生物、色素或代謝物 | 需存在適當生物圈、光照、營養循環及濃度條件 |
| **N3：已知非水液體或特殊氣候** | 在相應溫壓可有非常態地表液體；不適合人類裸露活動 | 僅在符合溫度、壓力與化學條件的天體生成 |
| **奇蹟／工程特例** | 需要整顆行星都可直接飲用、長期食品級穩定或超文明工程 | **不屬於本篇普通星球機制**，參照 WORLD-01／WORLD-06 |

地球局部類比 ≠ 已證實存在另一顆對應外星行星。較罕見的 **PB07 夜光奶海** 也不因此升級成普通高頻事件。

**命名慣例**：名稱是玩家或地方船員的視覺／嗅覺綽號；正式軍圖可用「高鹽色素湖」「有機質富集海」「碳氫冷液海」等中性名稱。PB 是**環境／生態模板 ID**，不是十二個完整星系 ID；一顆星球可有多區域，也不是每局都抽得到這十二種。

### PB01「水蜜桃汁海」的三層界線

1. **觀測層**：衛星看見橙粉海岸與浮游生物顏色；星艦偵測到特定揮發性香氣，可能被人類或同鄉類比為桃香。
2. **推論層**：類比地球微生物可生產帶桃香的 **γ-癸內酯**；外星海洋的同類化學途徑是【假想生物學】。氣味感知、空氣傳播、氣壓與風向影響觀測，不能從軌道上「聞到整顆星球」。
3. **可食層**：**未經檢測，不能直接喝海水**。採集的水、有機質可透過既有處理／食物列印設備轉成抽象「原料」；只有經物種安全與處理驗證才可列為可食。稀有「全海就是可喝果汁」屬 [WORLD-01](19-edible-worlds-and-food-planet.md) 的奇蹟世界，而非本模板預設。

## 三｜如何併入低價值普通星系（不額外加地標）

**【生成提案】** 先用世界種子決定恆星、岩質行星／衛星、溫壓、地表液體、地熱、鹽度、初始生態和礦產；再只在**物理條件與星系類型相容**時附加一種或少數 PB 環境。沒有生命條件，不能亂抽 PB01、PB06、PB07。若是土衛六式低溫液態，可選 PB09，但不可以同區域無解釋地塞入溫暖桃香海。

依既有 [C15 星系目錄](15-star-system-catalog.md) 的 **P21–P30 低產農業、P31–P40 原始生態、P51–P60 普通環境異常**等適合區段作為優先候選；P01 無行星、死寂低收益星系不應硬補景點。**低價值代表戰前可採軍事工業資源較少，不等於完全無生態特色**。

按以下次序抽選而非每顆星球「十二連抽」：

1. **種子→客觀物理**：恆星光譜、軌道、溫壓、地質、水文、營養來源、生命可能性；先定真實礦物與能源價值。
2. **候選過濾**：需要液態水／高鹽／地熱／冰川／濕地／極寒碳氫環境的 PB 類型分別檢查條件；無合格候選時保留普通景觀。
3. **少量生態覆層**：一般 PB 特徵不保證稀有獎勵；若發生 PB07 等特殊季節事件再明顯標示稀有度。**實際生成率、每局星系數均待決**。
4. **視覺和資訊**：依光譜、微生物色素、浮粒與地形生成縮圖色階；區分「戰前歷史資料」「當前環境」「本軍團採樣時間」。
5. **安全與經濟**：物理採集收益、我方／當地物種毒理與嗅覺偏好分開計算；不能用「好喝」替代「高能礦資產」。
6. **狀態持久化**：已見到的季節、採樣結果、事件與採收狀態由同一世界種子及存檔保存；重訪不重抽整顆星球。

**建議資料欄位【未實作】**：`biome_id` (PB01–PB12), `system_id`, `planet_id`, `region_id`, `climate_regime`, `surface_liquid`, `salinity`, `pH_class`, `pigment_source`, `aroma_source`, `requires_life`, `local_season`, `measured_hazards`, `species_safety_by_id`, `industrial_resource_value`, `prewar_survey`, `survey_observed_at`, `harvest_state`, `event_flags`. 未知保持「未知／待決」，不要拿數值 0 冒充測量值。

**與舊內容的分工**：
- **WORLD-01**：真正可以吃、甚至需要特殊生態才能成立的**超稀有奇蹟美食星球**。
- **WORLD-02～05**：奇幻美食生態、風味、巨獸與熟成狀態。
- **WORLD-06／BV01–BV20**：更接近飲料風味、泡泡地貌的奇特候選；部分需古代工程。
- **WORLD-07／PB01–PB12**：地球已有原理或最小外星生態假設的**普通環境覆層**。名稱與 BV 類似不代表新增一顆獨立星球；例如茶色水（PB03）不是可直接飲用的麥香紅茶（BV04）。

## 五｜驗收契約（規格已列，實測 Not run）

- **PB-T01**：無海洋／地表液體、溫壓不符時不生成桃香海、氣泡湖或甲烷海；不把無行星系統加成有行星。
- **PB-T02**：N1 地球局部現象不會自動被敘述成全球可飲果汁；PB01 未檢測安全前不得增加即食補給。
- **PB-T03**：PB05 只在實際富氣／壓力條件符合時觸發局部危險，有預警與離開選項；不突然爆星或秒殺旗艦。
- **PB-T04**：含高能晶礦的行星不因有漂亮湖泊而被戰前軍圖降成低戰略價值。
- **PB-T05**：生成權重允許普通無事件星系；全圖不強制出現 PB01–PB12，也不佔用 30 個固定地標名額。
- **PB-T06**：同種子相同生成結果；採樣記錄與季節狀態存檔讀回一致，不重抽星球或重領資源。
- **PB-T07**：不同物種可以對同一海洋有不同味覺／毒理；中性地質資訊與軍圖資料獨立。
- **PB-T08**：未製作的內容保持「內容庫」，不因文件檢查成功而標為可玩。
