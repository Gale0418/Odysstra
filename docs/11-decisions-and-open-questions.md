# 11｜決策紀錄、已取代想法與待決事項

> **本文件為設計權威索引。** 多方 AI 的建議可參考，但**只有使用者親自更正／選擇的內容**應標為【已確認】。未決議題不得因文件寫得完整就變成「已設計完」。

## A. 已確認的核心決策（截至 2026-11-15）

| 題目 | 使用者確定／更正的方向 | 易犯誤讀 |
|---|---|---|
| 名稱 | **Odysstra**，由 Odyssey＋Astra 的融合造詞而來；倉庫已採此名 | 不要繼續以 Homeward Armada 或 Odyssera 當主名 |
| 主題 | 戰敗的附庸遠征軍帶十萬同鄉返回共同母星 | 不是最後港口／傳送站才算終點 |
| 戰爭規模 | 類似《群星》天國之戰，甚至是宇宙級大戰；前老闆遠古強權被輾平 | 不是普通兩個年輕帝國的局部戰 |
| 玩家處境 | 百艘左右完整作戰軍團，在巨人戰爭中相對只是小螞蟻 | 不是破爛難民／自動戰損見底的殘部 |
| 世界地理 | 主要穿過曾是友軍但**不是前宗主國核心本土**的地區 | 不必把前宗主國廢墟設定成返鄉唯一通道 |
| 地圖 | 會戰前發的極詳細舊軍圖**停止更新**，歷史仍有參考價值 | 不是開局全部是假資料／全部巨大問號 |
| 星系內容 | **30 個有名有特色事件的星系**，其餘普通星系由隨機低價值組合生成 | 不等於全遊戲只有 30 個，也不必固定每局 100 個 |
| 普通星系 | 包括真的無人、少礦、低產農業、原始文明保留、無行星鬼地方 | 不可每個水星系都藏神器 |
| 航線 | 玩家能自由航行、回頭、繞路、甚至故意撞紅區 | 不做單向 FTL 路線或自動死路 |
| 返鄉成果 | 有多少人回家由玩家操作與損失決定 | 不強迫少數存活的悲壯劇情 |
| 母星 | 抵達母星即 **Happy End**，後續先不用管 | 不強制母星背叛、最終 Boss 或多結局懲罰 |
| 飛昇與人力 | 老兵長壽、厭戰，十萬人以數字表示 | 不用老死倒數、不做十萬人 NPC 模擬 |
| 後勤 | 食物列印機；消耗抽象「原料」，補給可買，燃料可買或在恆星旁採集 | 不要逐餐管馬鈴薯／把燃料限制成唯一獨占資源 |
| 玩家經濟 | 可採礦、打撈、交易、造船，**搶劫也是選項** | 不當道德抉擇遊戲，不強制玩家當好人 |
| 開局配船 | 可微調艦船類型；運載／居住艦選少，開局人口就變少 | 不可無視十萬人的艦船容量 |
| 戰勝國 | 按**遊戲時間**與局勢推進；神器／高價值戰略資產可能引導接管方向 | 不必固定一條紅色線向右刷 |
| 監控 | 戰勝國擁有全圖艦隊監控能力；追不追看戰略優先度、距離與其他威脅 | 別把「他不管你」改成「他雷達看不到你」 |
| 旗艦 | 玩家在旗艦，旗艦被擊沉＝Game Over | 不必全艦隊全滅才失敗 |
| 非線性沙盒 | 不回家也能在中途發展、造船、當軍閥；厭戰老兵可吐槽 | 不急著做完整 4X 建國模式 |
| 遠古科技 | 不受《群星》科技樹限制，前老闆留下不可思議的奇葩日用品與軍備 | 不要把每個 DLC 科技當原宗主國標準裝備 |

## B. 方向明確，但細則未定

- **2D 戰鬥**：像《遠行星號》的平面視覺，但超過十艘逐艘操控太繁瑣。偏向《群星》式自動戰鬥＋少量艦隊級命令；**尚未正式選擇 A/B/C 操作方案**。
- **30＋70**：曾說「30 個有名字有事件的星系＋70 種隨機組合但是低價值」，後續有人寫成 70 個星系。**70 的精確意義、每局實際星系數待決**。
- **泰坦開局**：可以想像玩家選高階泰坦就被戰勝國列高優先處理目標。是否開放泰坦、配置點數、船數及修復成本均待平衡。
- **局部政治**：星系原戰前功能應影響戰後事件；但各派怎麼打仗、多少星系同時更新尚需技術設計。
- **旗艦與人員**：旗艦沉即敗已明確，但司令能否戰前轉乘換旗艦仍待決。

## C. 已被後續修正／不要重新採用

- 「海參崴式中繼站是唯一終點」 → **已取代**：終點就是共同母星；港口至多是途中的交通設施。
- 「玩家一定要在道德兩難中犧牲同鄉」 → **已取代**：以實際航行、戰鬥與資源結果決定傷亡。
- 「艦隊只有 15 艘真船＋90 艘純背景裝飾」 → **已取代**：所有實際艦艇應有戰略狀態，但戰場是否同場上陣尚待定。
- 「玩家要逃跑、不能造船，不然會變海盜王」 → **已取代**：可以發展與回頭，世界依玩家行為反應。
- 「每天有老兵因自然壽命老死」 → **已取代**：飛昇長壽，不能用老死逼返鄉。
- 「地圖開場就是謊言／問號刮刮樂」 → **已取代**：真實但停更的戰前資料，玩家逐漸學到需核實現況。
- 「紅區像毒圈，走進去直接死亡」 → **已取代**：戰勝國的實際駐軍及政治控制，可以被玩家接觸甚至進攻。
- 「戰勝國不知玩家在哪」 → **已取代**：戰勝國有哨兵陣列類型的全圖監視，只是受戰略優先度制約。
- 「返鄉後強制家鄉背叛、最後決戰或悲劇」 → **已取代**：到母星就是 Happy End。
- 「英文名 Homeward Armada／Odyssey 副標」 → **已取代**：使用者選了融合造詞 Odysstra。
- 「全都必須是嚴肅現實科技」 → **已取代**：前老闆科技可以極度荒謬，但彩蛋不能支配主玩法。

## E. 文件中的數字是什麼性質

**確認的敘事量級**：十萬同鄉、百艘左右／百餘艘艦隊、30 個有名地標、宇宙級會戰、半個銀河的返鄉路。

**不是定案的遊戲數值**：每天消耗、各種船建造工時、敵國每回合接管率、泰坦仇恨權重、出貨時間、敵方艦隊數量、低價值星系掉落率、單局遊戲長度與存活率。

## F. 明確避免需求膨脹

只要提案要求再加一個獨立巨型模擬系統，必須問：「**沒有它，五個星系的小原型是否仍可驗證返鄉玩法？**」若是，應延後。參考 [09](09-production-risks-and-prototypes.md)。
