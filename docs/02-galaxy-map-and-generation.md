# 02｜停更軍圖、星系生成與自由航路

## 重要糾正

**【已確認】這不是一張故意騙玩家的假地圖。** 它是前遠古宗主國在戰爭期間供附庸軍團使用的精細導航圖，**因宗主國戰敗而停止更新**。想像使用一張過期 Google Maps：商家可能倒閉、道路可能封閉、地理位置通常不會莫名亂移。

玩家開局能看到戰前星系座標、航道、舊控制權、補給站及軍用設施記載。**玩家最初不必知道地圖不可信**；實際探索才慢慢感受到現況與紀錄的落差。

## 建議的兩層情報

| 層 | 內容 | 是否可過期 |
|---|---|---|
| 戰前軍圖（靜態） | 星系座標、恆星、行星與星門歷史、戰前功能與所屬、官方航線 | 作為歷史記錄永久保留 |
| 戰後現況（動態） | 星門是否仍可用、補給站存亡、軍閥、海盜、駐軍、價格、戰損、資產可用性 | 隨遊戲時間變動且持續過期 |
| 玩家自記錄 | 偵察日期、危險標記、親歷戰鬥、已知商人與礦點 | 保留歷史標記並標示觀測時間 |
| 戰勝國情報 | 已掌握的接管進度、巡邏路線、敵方艦隊動向 | 依情報品質及延遲刷新 |

**【提案】** 狀態分為「戰前記錄／最近核實／過期情報／無確認」，以時間戳與已知可信度呈現；不要所有星系一開局就硬貼巨大問號，更不要每次出入任意換生成結果。

## 規模的精確口徑

- **【已確認】30 個有名字、有專屬事件的地標星系**，並不代表所有 30 個在每次遊玩都一定有重大事件。
- **【方向】另有 70 種低價值星系隨機組合／普通星系內容**，例如真的無人區、貧瘠礦區、低產農業區、低等文明保留區、幾乎沒行星的恆星系。
- **【待決】** 70 究竟是模板組合數、每局生成數，還是初版目標數；不可自動說成「每局固定總共 100 個星系」。
- 地標的名稱／個別背景尚未經使用者逐一確認。具體 30 個候選見 [15](15-star-system-catalog.md)。
- 每局不應體驗全部事件。讓星系的地理與歷史提供重玩的連續性，戰後政治與事件隨種子／時間變化。

## 地圖／移動原則

**【已確認】** 自由航行、回頭、繞道、分遣、探圖、主動撞戰勝國紅區都允許。不是單方向星門鐵路，也不是母星只能經某座終極撤離門抵達。

**【提案】** 使用「恆星系節點網＋星系內 2D 航行」的雙層結構。高效率星門／超空間航道形成瓶頸，普通航行或其他跳躍方式提供繞路，但成本較高。航道是否能任意跳、燃料公式、最短與最長航程尚待原型測試。不能把星門設定成唯一物理方式來強迫線性流程。

**地理語意：** 戰前繁華商港未必現在就是海盜基地；更合理的是商港有利可圖，附近無人星系與小行星帶形成海盜窩。戰前要塞因持有軍事資產更可能形成軍閥；高戰略價值工業區更可能被戰勝方優先接管；偏遠農業區也可能相對平靜。

## 因果生成管線【方向／提案】

1. **地理骨架**：固定母星與主要地標，建立星座標與多條互通航路；先檢查可達性。
2. **戰前屬性**：繁華度、工業、農業、軍事、交通樞紐價值、原所屬、戰時軍事資產。
3. **戰爭創傷**：遭轟炸程度、星門存亡、艦隊殘骸、移民流失、前宗主國設施是否遺留。
4. **戰後秩序**：政府瓦解程度、軍閥掌握軍港或科技能力、海盜據點地理誘因。
5. **當前態勢**：軍閥交戰、貿易、戰勝國接管時間、巡邏、補給價格。
6. **玩家影響**：打撈、打敗海盜、協防、造船、搶劫、占領等操作改變後續結果。
7. **存檔**：生成種子＋所有已發生變動必須保存，不可玩家重返就重新抽籤。

目標不是每個星系有大戲，而是**「戰前身分 → 戰爭後果 → 戰後政局」有因果連續性**。

## 普通星系的正當用途

- 貧瘠無人系：停泊修整、低能耗航線、可能避開地方軍閥。
- 低產礦區：少量原料，資源／時間是否值得由玩家判斷。
- 農業小殖民地：有限貿易與補給，無需有完整劇情。
- 保護區：原始文明及原宗主國限制；接觸政策與隱蔽性可有小事件，但不必每次觸發。
- 無行星的鬼地方：真的空、真的沒大寶藏；可用來穿越、採集恆星燃料、短暫整備。
- 航道附近小行星帶：海盜藏身及伏擊點，與商路相互作用。
- 廢棄中繼站：低價修復資源與偶發戰時記錄。

讓安靜地方真的安靜；否則玩家每跳都收到「發現古代殲星武器」，稀有度與世界尺度雙雙崩潰。

## 建議資料欄位

| 欄位 | 含義 |
|---|---|
| system_id / seed | 穩定識別、程序生成一致性 |
| coordinates / links | 舊導航座標、可行航線與障礙 |
| prewar_owner / prewar_role | 戰前所屬、原來用途 |
| prosperity / industry / military | 戰前繁華、工業、軍事屬性 |
| war_damage / gate_state | 戰爭破壞、星門當前狀態 |
| present_owner / patrols | 目前控制勢力、駐軍巡邏 |
| relic_asset / access | 可能殘留的軍事遺產及可用狀態 |
| observed_at / intel_quality | 玩家最後核實時間、資料可信度 |
| narrative_flags / world_events | 地標事件與世界變動狀態 |

所有量化權重、各類星系產率、時間間隔**待測試，不能從本文件的舉例反推為正式平衡數值**。

## 地圖生成的硬性驗收

- 母星和起點可辨認，彼此之間至少存在可實行的返鄉方案。
- 戰前星圖歷史不能被「現況更新」改寫；星門被炸應顯示損壞。
- 接管區推進不允許無預警封死全部航路且無可行對策。
- 同一種子、同一存檔重讀，已探索的星系狀態與事件結果一致。
- 偵察應提供值得付出分遣成本的情報，卻不應是每跳強制的無聊流程。
- 所有地標／程序事件不得無因果地反覆刷出獨一無二的古代神器。

## 2026-11-16｜補充：星系軍事價值與物種美食價值不是同一張評級表

**【使用者明確修正】** 共通物理下的大量高能晶體、稀有礦產、重要軍工能源或戰略航道，對高文明有客觀用處，當年軍圖不應毫無緣由漏評高價值。**低價值普通星系可以擁有非常美味的生態系**，因為前宗主國的軍事／工業指標、食物列印供應與帝國物種的味覺／毒理未必重視它。這不等於帝國連地質調查都不會。

在舊圖中分開保存「礦物／能源與軍事評級」「所針對的物種與生化危險」「戰前官方評估日期」。玩家後來的本族可食性、地方食材貿易或生態調查是**新情報**，不回頭改掉歷史軍圖。普通生態星的風味覆層見 [WORLD-02](world-02-gourmet-ecosystems-and-imperial-low-value.md)；不能強制在所有貧瘠系都生成美食。
