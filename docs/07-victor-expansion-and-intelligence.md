# 07｜戰勝國接管區、全圖監控與戰略注意力

## 這不是木星輻射，而是有理智的敵國【已確認】

- 戰勝國紅色接管區**按照遊戲時間**向戰後星域推進。
- **方向與速度會受星際局勢改變**：某地出現前宗主國超級武器、軍港或神器情報，戰勝國可能改調優先資源進行接管。
- 接管後出現**強大的正規駐軍、軍事巡邏及交通管制**；玩家是戰敗方軍團，可能被標記為敵對。
- **戰勝國確實有哨兵陣列類型的全銀河艦隊監視能力。** 不要再把「低調」誤讀成它完全看不到玩家。
- 玩家只是戰後無數亂源之一。戰勝國知道大致位置，也要衡量威脅、距離、調兵成本與其他戰略任務。
- 玩家可回頭、進紅區、突圍、搶劫或自由停留；紅區不是碰到就直接 Game Over 的物理毒圈。

## 關鍵拆分：情報 ≠ 重視 ≠ 攔截

| 維度 | 可能狀態 | 玩法意義 |
|---|---|---|
| 已知位置 | 哨兵陣列提供全圖艦隊訊號 | 戰勝國可知你在哪個星系 |
| 身分辨識 | 殘軍／商隊／持有特殊裝備／身份待核實 | 影響對玩家的威脅判斷 |
| 戰略優先級 | 普通殘軍、非法武裝、持有泰坦、奪占遺產 | 決定是否派正規軍調查或追擊 |
| 作戰可及性 | 距離、航道、駐軍部署、正在打別的仗 | 決定即使想抓也能否迅速趕到 |
| 地方反應 | 搜查、警告、通行管制、伏擊、重兵回收 | 在星圖上形成可見且可預期的行為 |

**【提案】** 將「軍力／古代資產、對接管區攻擊行為、地理距離、可用敵方艦隊與其他目標的重要性」作為優先度因素。不要定死某條數值公式或「只要選泰坦敵方百分百立即瞬移到面前」。

## 階段型接管【方向】

1. **尚未接管**：前友軍政府、海盜、軍閥，各有秩序；戰勝國或許只有情報監控。
2. **先遣接管**：偵察、外交要求、檢查點、軍事設施清查，重要星門優先。
3. **穩定占領**：正規艦隊與守軍巡邏；海盜被壓制，商路可能比較安全，但玩家通行風險增加。
4. **軍事調整**：別處出現更高價值威脅時可能撤調部分前線兵力，不一定永久固定加速向家推進。

紅區面積變大，**不等於所有已染紅星系都處於相同戰鬥強度**。航道可能仍可用，地方官可能交易，部分偏遠系更晚接管。

## 戰略資產回收與「核擴散」事件

前宗主國敗亡後，附庸國可能持有不能完全控制的戰略武器、失聯船塢、軍圖、古代能源設施。戰勝方接管通常優先掃描這些區域。

**例子**：某個軍閥公開啟動古代巨構 → 戰勝國調動主力回收 → 玩家本來的通行要道巡邏減少，也可能因靠近該巨構而陷入交戰。玩家可以繞路、觀察、交易、搶奪，甚至故意散播情報（這是**提案，未確認會有情報造假系統**）。

## 可玩的軟性壓力

- 戰略任務隨時間推進，讓玩家不必被強制倒數；想留下來造船會有形勢變化。
- 高級艦會吸引更多關注，卻是有用的強力戰艦，不是純懲罰。
- 低配艦隊較不優先處理，但不能被寫成戰勝國雷達完全無法發現。
- 接管路線受交通條件與軍事需要約束；兵力沒有合理來源就不會瞬移。
- 玩家要有清楚的情報提示：哪裡已被接管、最近觀測時間、敵方主力／封鎖情報品質。
- 任何「接管區死路」都要有偵察、外交、資源準備、繞道或戰術突圍等可理解對策；禁止無預警全圖即死。

## 原型驗證

**P-001 提案**：五個星系，紅方按遊戲日數從一個節點接管到要道；同時另一地出現重要遺產，紅方應能調整部署。觀察玩家是否理解風險、是否能利用自由路線與補給應對。

**不要假裝已決定**：每天接管幾個星系、哨兵陣列偵測延遲、通行判定、追兵速度、泰坦優先度數值、造假情報能力皆需遊玩測試。
