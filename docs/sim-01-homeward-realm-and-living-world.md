# SIM-01｜母國獨立存續與活世界：多身分推演、原型及驗收

> **2026-11-27｜使用者決策：方案 A。** 母國在宗主國敗亡後完整存續、維持獨立，擁有自己的領土、政府、工業、國防艦隊；不強制淪陷、割地、投降、分裂或背叛。十萬同鄉、百艘左右是遠征軍的規模，不是母國人口或全部艦隊。抵達共同母星依既有決策即 Happy End。母國名稱、疆界、艦隊數、外交安排、科技路線仍待決。下文的星系、貨量、日數與行為均是**推演／測試預設**，不是正式數值或地標定案。

## 1｜現況與問題

本次起點是 `b47ee72a7108a6b31cd67e99d283240d067e3392`；其 main 樹共 58 個檔案，以設計文檔及文檔檢查工具為主，未找到正式遊戲程式或可執行畫面，無從針對既有遊戲做實機回歸。依 [C11](11-decisions-and-open-questions.md)、[C15](15-star-system-catalog.md)、[C07](07-victor-expansion-and-intelligence.md) 與 [C16](16-playability-contracts.md) 的既有邊界建立獨立因果原型 SIM-01。它不取代 P-001，不決定正式引擎，不加 30 個地標的固定配額。

母國何以不出動國防軍跨半個銀河？【提案】遠古宗主國的跨境後勤與通行秩序崩解；母國仍須保護自己完整國土，不宜把主力派往戰勝國及軍閥控制區。可提供情報、外交協調、前進補給和有限救援；遠征軍進入本國航道後，國防艦隊在軍籍確認後接應。這不是母國無能、不願救人或獨立靠敵國看不見。母國可有自己的外交和軍力，敵國的接管部隊則有其他高價值目標。本原型只模擬不侵犯母國的方案 A 測試情境，不宣稱母國無敵或戰勝國永不能進攻。

## 2｜暫時作為居民生活：三種情境 × 九種身分

以下是**原創推演而非實測**。太空真空不傳播一般聲音；船員可聽見座艦結構振動、儀器、通訊、生活區人聲。探索不等於必須降落或作戰。

| 身分 | 正常日常：所見、所聞、行動 | 特殊情況 | 極端情況及後果 |
|---|---|---|---|
| 遠征軍艦長 | 讀舊圖、聽船橋輪值與其他艦隊通報、觀察補給商隊，決定是否偵察或直接前進 | 前港口主人更換，收到招募或舊軍籍許可；驗證身份、交涉、改道 | 航線突遭封鎖、旗艦受損；警告、護衛、撤退。旗艦擊沉即 Game Over 的既有規則不變，尚未實作戰鬥 |
| 後勤／維修員 | 餐廳的原料列印機、船塢工作燈、定期損耗及排班；使用共通原料與備件 | 回收陌生文明材料或模組，設備相容性需要核實 | 供應鏈中斷；庫存不足先告警，替代港口、重新分配、修復優先度；不逐人模擬醫療與饑餓 |
| 地方商船船長 | 比較庫存與價格、裝貨、沿航線運輸、卸載 | 航道關閉，重新找買家與安全路線 | 遇海盜或接管封港，貨物實際減少／滯留，目的地缺貨；不憑空刷新貨物 |
| 海盜船長 | 觀察商路，尋找能獲利的弱小目標 | 發現百艘遠征軍，評估戰力後撤走、偽裝或交易 | 遇正規艦隊或接管，撤退、投降、失去基地；無需每次自殺式戰鬥 |
| 地方軍閥／港務官 | 發薪補給、港口檢查、維持工業與領地 | 帝國軍籍服務失效，與地方勢力協商、調整價格或通行 | 勝方部隊實際到達才接管；控制權改變令民用貿易繞道或停擺，不抹去歷史記錄 |
| 巨型植物星居民 | 在樹冠工廠與運輸平台採集再生材料；葉片摩擦聲、城市交通、原料裝載 | 巨植開花、長出新組織，採收期與物流改變 | 戰後貨運中斷、產地累積庫存、消費港缺貨。植物是固定生產資產，特殊產業可競逐具名地標；不因「植物」直接判低價或高軍事價值 |
| 宇宙巨獸 | 沿合適物質與能量來源遷徙，休眠、繁殖、遠離騷擾 | 酥殼日眠魚翻身，掃描辨識；航行員避開並留下觀測 | 殘骸分布或棲地改變導致移動；局部交通受影響。非必殺 Boss；真正碰撞、生命維持及風味處理仍待測 |
| 母國國防軍 | 巡邏國土、管理歸航門、維持民用通行 | 接收失聯遠征軍軍籍，回報司令部，派出接應艦隊 | 外國局勢惡化時集中守衛本土；不擅自將方案 A 改為母國淪陷。護航抵達的感情強於強制最終 Boss |
| 母星居民／老兵家屬 | 日常工作休閒、新聞、繁忙民用星港；國內政府與社會照常運作 | 得知失聯軍團接近國境，家屬查詢返國訊息、港口準備接待 | 航程受阻時在家鄉等候與協調救援；不強迫母國背叛或因玩家延遲而毁滅。到家後可用廣播、艦艇旗幟、返鄉名冊營造情緒 |

## 3｜活世界的因果契約

- **時間**：唯一遊戲日。運行時即使玩家不操作，市場生產／消耗、商船配送、海盜判斷、勝方調兵、巨獸遷徙持續更新；暫停、隱藏頁面、讀檔、結算不按現實時間補跑。正式遊戲仍遵守 [S01](16-playability-contracts.md) 的單一時鐘。
- **貨運**：固定生產資產→裝載後扣除來源庫存→商船依有效航線逐站移動→卸載增加目的地庫存；掠奪減少在途貨物、消耗減少庫存、缺貨提高價格。航線中斷→商船改道／改買家→原目的地短缺；並非只有事件文字。
- **政治**：勝方持有玩家位置情報，但以戰略資產與路程選目標；移動到目標後才更新控制權，不即時瞬移。玩家仍可進入紅區（原型無實際交戰，不把此解讀為永久安全）。
- **生態**：巨獸有位置和移動週期，能因可行航路改變遷徙，僅近距掃描才會獲得本艦情報；巨型植物產地則是固定生產節點，不複製成另一隻 MB 巨獸。參照 [WORLD-04](world-04-pseudoplanet-gourmet-megafauna.md) 與 [WORLD-07](world-07-plausible-planetary-biomes.md)。
- **家鄉**：母國節點在此情境不被勝方選作接管目標，國防艦隊位於母星，抵達歸航門觸發接應並在相鄰國內節點實際移動；抵達母星停止本局並完成 Happy End。不是母國所有星系永遠免疫任何戰爭的物理法則。
- **情報**：歷史控制權、當前世界狀態、玩家觀測時間三層資料分離；觀察者模式供開發檢查，軍圖模式屏蔽遠方即時庫存、巨獸、接管與其他事件。正式玩家情報系統仍待擴充。

## 5｜可執行原型及操作

- [SIM-01 網頁入口](../prototypes/living-world/index.html)；[模擬核心](../prototypes/living-world/world.js) 與 [Node 測試](../prototypes/living-world/test-world.cjs) 分離，不依賴外部套件，使用 DOM/SVG 作診斷圖，正式引擎未定。
- 八個**測試**星系（其中天穹林廠仍是具名地標候選）、十條雙向航道；三個預設情境：正常、商路中斷、殘骸連鎖危機。百艘十萬人只以聚合數值呈現。
- 正常起始可按「暫停時間」或等待自行演進；選擇相鄰星系下令航行，推進一日到達；原料可交易、恆星補燃料花一日、掃描更新情報。每段 8 燃料、測試信用點、商品量及一天一跳只是測試預設。
- 選擇 A→B→D→E→F→G，或其他有效路線返鄉。瀏覽器可用的情況下可保存本地 JSON 快照；無權限或壞格式不覆寫現局。快照序列化重播已通過程式測試；真實瀏覽器持久化仍未驗收。

## 6｜驗收結果與證據（2026-11-27）

**本地實測**：Node.js v22.16.0，`node --test prototypes/living-world/test-world.cjs`；13 個測試全通過，0 fail。包括不操作自主演變、物資守恆、封閉與恢復、航行中斷退回未消耗燃料、先移動再接管、資源扣除、母國接應結算、海盜避戰、觀測不偷更新、可重播快照、損壞快照檢查及實際商路改道。正常／封鎖情境第 2 日，商船分別在銀灣與灰印，正常情境損失 6 貨物，封鎖情境在我軍所在位置沒有被搶；第 10 日銀灣庫存分別為 14／0、價格為 3／4（純測試單位）。

**瀏覽器實測**：本環境 Chromium + Playwright，1440×1000 桌面與 390×844 手機尺寸。因環境管理政策阻止直接開啟 file:// 與 localhost，使用相同 HTML 內嵌同一模擬核心的 `page.set_content` 測試（[重現腳本](../prototypes/living-world/playtest.py)），截取 5 個狀態畫面，確認星圖啟動、時間自行前進、暫停、兩種封閉情境、觀測資訊遮蔽、交易、航行、母國接應、結局停時、手機無橫向頁面溢出及無 JS 頁面錯誤。原型初版手機標籤偏小，已放大及改善控制列折行；商路封鎖原先發生過晚、海盜移動後沒有重新評估玩家，已修正並重測。

**限制**：因 about:blank 沒有可用的持久化來源，實際本地儲存寫入／重開讀回為 Blocked，僅驗證無權限時正常報錯及 Node JSON 重播／格式拒絕。未測 Safari／iPad 實機、百艦戰鬥、3D 資產、真實音效、居民 NPC、全銀河效能。不得把上述 13 個原型測試算成 C17 的正式 P-001 測試通過，也不得聲稱已製作完整遊戲。
