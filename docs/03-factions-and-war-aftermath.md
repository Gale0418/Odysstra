# 03｜戰後政治、友軍領土與軍事遺產

## 誰是誰【已確認】

**前宗主國（前老闆）**：科技遠超普通文明的遠古覺醒級帝國，發給附庸部隊精密軍用星圖並命令他們參與宇宙級大戰；已在正面大戰敗亡，核心地帶大致遭戰勝國擊潰／占領。**不把其核心領土當成我們返鄉必經的整條路**。

**玩家軍團**：昔日附庸中的完整遠征軍團。十萬人來自同一顆母星，仍有可運作的軍事指揮鏈與戰鬥艦隊；不等於宗主國本身，也不等於僅剩十萬人的全部文明。

**昔日友軍／附庸領土**：玩家主要穿越的地區。當年與我們在同陣營，不代表戰後仍然忠誠、友善或服從。可能獨立、內戰、稱帝、轉投戰勝國、與別的軍閥結盟。

**戰勝國**：遠古軍事工業與情報優勢壓倒性的銀河霸權。已贏得大戰，但還要清理無數戰後亂源、占領要道、回收高危戰略資產。**能全圖監視不代表對每一支遠方小艦隊都即刻動手**。

## 典型地方勢力【提案】

| 勢力 | 利益與行為 | 與玩家的可玩互動 |
|---|---|---|
| 前友軍自治政府 | 保護居民、維持補給，避免被戰勝國懲處 | 貿易、護航、軍港准入、結盟 |
| 要塞軍閥 | 有完整部隊和船塢，渴望擴張或取得名望 | 收編邀約、勒索、打仗、交易、雇傭 |
| 工業財團／船塢董事會 | 控制生產線及稀有零件 | 維修、訂單、交換技術、爭奪控制權 |
| 黑市海盜聯盟 | 掠奪商道、洗貨、控制走私港 | 襲擊、威懾、賄賂、購買物資、當海盜 |
| 帝國忠誠殘軍 | 不承認戰敗，依舊執行舊命令 | 說服、會合、協同撤離、誤判敵我 |
| 地方共和國／革命勢力 | 擺脫前帝國軍事統治，防止軍閥復辟 | 外交、護航、過境、衝突 |
| 其他返鄉遠征軍 | 也失去上級、也要跨越銀河回鄉 | 交換星圖、同行一段、救援、貿易 |
| 戰勝國地方行政／駐軍 | 接管、安全、戰略遺產回收 | 通行、執法、檢查、被追擊、局部交易 |

這些是**勢力原型**，不是已確定每個星系都要有一個國家、每個國家都要完整模擬政治制度。

## 「蘇聯解體核武散落各地」的核心結構

戰時宗主國可能將超級船塢、武庫、戰略飛彈、古代維修設施、監控節點等部署在友軍／附庸區。宗主國敗亡後，**所在地、所有權、控制權、維護能力不再等價**。

對每份高價值資產可用以下狀態（未必需要分成獨立系統）：

1. **實體是否完整**：是否已受戰損、缺能源、缺人員、被封鎖。
2. **控制權是否可用**：軍閥占領不等於握有啟動碼；昔日軍用識別碼有時可通行。
3. **維護／生產能力**：會啟動一艘古代艦不代表能量產；大型固定巨構不應能隨意塞進貨艙。
4. **戰略價值與曝光**：越能改變星域力量平衡，越可能吸引戰勝國回收或地方軍閥爭奪。

這就是軍閥有強弱層級的理由：普通海盜搶貨、有正規部隊的要塞軍閥控制軍港、少數勢力占據無法理解的古代設施。不要「30 個地標全有核彈」。

## 戰前功能如何形塑戰後

- 商業繁榮 → 貨流、財團與黑市仍有價值；海盜常躲在**旁邊無人區**，而非必然占領市中心。
- 要塞／軍事駐地 → 部隊、武庫、軍官仍在，容易形成軍閥或自治安全政府。
- 航道樞紐 → 星門控制權與收過路費的爭奪；毀壞則造成長距離繞道。
- 工業造船星 → 船塢可修復／可爭奪；控制者不一定有材料、工人、藍圖。
- 低產礦農區 → 可能躲過大戰，仍然普通生產；沒有必要每顆都有神器。
- 前宗主國核心舊區 → 可能被徹底摧毀或戰勝國重兵占領，不是返鄉常規航路。

## 戰勝國不是機械式邪惡追兵

- 目標按戰略價值排序，例如超級船塢、未回收武器、交通瓶頸、敵對大型艦隊。
- 有些接管讓商路安全、海盜變少；對玩家卻同時代表檢查、軍事封鎖和身份風險。
- 「放行」可能因外交、當地官僚、地方交易、軍事資產談判、成本效益等不同理由出現；不用先寫一個全銀河統一陰謀。
- 高階艦隊、開局泰坦、襲擊駐軍或公開動用戰略遺產，能讓玩家從低優先度變成重要目標。
- 勝方全圖監視能力見 [07](07-victor-expansion-and-intelligence.md)，不應被偷換成它不知道玩家的位置。

## 可能的地方小故事【內容庫】

- 前友軍上將昨天還是戰友，今天自稱總督，提出護航交換通行權。
- 三個原盟國政府爭執誰擁有前宗主國寄放的船塢，玩家只是想修引擎。
- 要塞囤有禁止啟動的戰略武器，戰勝國優先調兵回收，玩家可旁觀、繞路或趁亂。
- 商業主幹道本身正常營業，周邊貧瘠星系成為海盜伏擊網。
- 新成立的自治共和國怕玩家來恢復前帝國統治，卻可能願意供應燃料。
- 另一支與我們方向相反的返鄉軍團，交換新地圖及修船零件後各自離開。

## 避免的不合理設定

- 不假設所有前友軍都自動變成敵人；也不假設全都記得友情而免費放行。
- 不讓普通軍閥三天內量產數十艘遠古泰坦，除非有清楚且受限制的遺產機制。
- 不認定戰勝國必然財政崩潰、必然進入頹廢期、必然在背後指使所有事件；這些都曾是腦洞，未獲使用者拍板。
- 不能把現實歷史核武的地點、指揮權、移交過程與本作虛構武器的控制能力混為一談。

## 與最新戰爭尺度的對接

**【使用者確認】**兩個遠古霸權都在用規則級裝置互扁；前宗主國不是因為完全不會使用神級科技才戰敗。軍備供應、反制、決策與部署等是可用解釋候選，不指定唯一敗因。戰後回收與接管因此可涉及仍能運作的高位軍備，而非僅有傳說。

「玩家位置被看見」與「玩家啟動的神器被識別、被提高處理優先度」不同。舊軍籍、通訊廣播與交易留下的紀錄可以提高後者；不因此推翻戰勝國已具備的全圖艦隊監視。

## 2026-11-27｜我方母國並非前宗主國【已確認方案 A】

母國完整獨立存續，有其政府、軍隊、工業和領土；宗主國敗亡不自動等於附庸全境亡國。**【提案】** 其主力國防艦隊優先守護本土，跨境救援受外交、航道、戰略風險與補給限制。母國接應不是靠戰勝國看不到玩家；勝方在本情境優先其他戰略目標，並非設定成永遠無法攻打母國。[SIM-01](sim-01-homeward-realm-and-living-world.md) 已做簡化原型驗證。
