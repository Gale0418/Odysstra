# W04｜規則模組、神級能力、魔法艦隊術式與要塞炮

> **重要：本章屬【歷史腦洞設定／內容庫】。** 使用者提供「普通規則模組／神級模組」的原始名字與功能；後面的系統化細節、規則裁決、SCP 類比與要塞炮階級是【提案】，**不代表已決定納入《Odysstra》的玩家裝備**。世界觀可以存在古代不可思議科技，不代表海盜與返鄉軍團能量產它們。

## 1. 艦載武器之上，另有不同尺度的科技

| 層次 | 做什麼 | 戰術性質 | 使用狀態 |
|---|---|---|---|
| 常規／極端艦載 | 實彈、射線、導彈；重力、空間、維度類至次元切割 | 造成物質、場與空間的戰鬥事件 | 歷史科技名稱 |
| 艦隊／戰區術式 | 召喚、預知、幻術、死靈、結界、時間加速 | 改變整個戰場的編隊、情報與節奏 | 【提案】 |
| **普通規則模組** | 分身／投影／時間備份 | 改變「同一存在有幾個實例、何時能還原」 | 使用者親貼歷史名字與概念 |
| **神級規則模組** | 存在抹殺、必死、境界分割、傷害定義、萬象修改 | 改變事件是否成立與戰鬥結算 | 使用者親貼歷史名字與概念 |
| **要塞炮／宇宙儀式** | 因果、真空、宇宙膜、世界線乃至多重宇宙 | 針對「戰場存在條件」而非單船 HP | 【提案】；使用者提出「要塞炮應能轟多重宇宙」、正式提及「存在抹殺炮」 |

這不是已知物理可造的武器排序。越往下越是以科學詞彙包裝**魔法／本體論規則**；要有清楚「作用域、反制、代價」才能適合遊戲。

## 2. 普通規則模組：使用者原始概念【歷史設定】

| 名稱（照原話） | 原始描述 | 與另外兩個「分身」的區別 | 設計約束【提案】 |
|---|---|---|---|
| **三千世界** | 將**不同次元**的自身召喚到場上 | 平行宇宙的其他個體／艦隊 | 需要跨宇宙識別、召喚成本與回歸規則 |
| **事項疊加** | 將**不同時間**的自身召喚到場上 | 同一存在的不同時間切片 | 同一人物／艦體狀態衝突；「事象疊加」可作編輯別名，**不偷偷改原名** |
| **重複觀測** | 將**不同空間**的自身召喚到場上 | 同一個體的多重空間實例 | 同步限制、作用範圍、是否共享損傷 |
| **時間回溯機制** | **無法回到製造之前**；像系統還原一樣保存備份 | 不是把整個宇宙時間倒轉，而是還原保存的狀態 | 快照存在哪、是否包含敵軍、還原後損失與物品如何避免複製 |

**這三種不是「普通分身術換三個名字」：**分別在宇宙分支、時間與空間三個維度進行複本實體化。投入艦隊戰可升格為「不同世界艦隊參戰」「同艦多時間版本同場」「多處共享一艦身分」，但這些規模是**拓展提案**。

**時間備份規則**可以寫成：
- 製造與啟動時刻 t₀，僅可建立 t ≥ t₀ 的備份；
- 「回溯」重建狀態，不自動改寫外部整個宇宙；
- 快照內容、其他人的記憶、已發射武器和已用資源是否還原尚待決；
- **避免無限複製資源**：若回存艦體但外界保留舊艦遺物，要事先定義悖論處理。
- 這是虛構科技，跟本作正常單機**讀檔系統**不同：不能把遊戲讀檔權限當成船在世界內擁有時間武器。

## 3. 神級模組：使用者原始清單【歷史設定】

| 使用者原名 | 原始效果 | 系統分析與互動【提案】 |
|---|---|---|
| **存在抹殺** | 敵人**從來沒有存在過**；單體技能 | 不能等同高傷害炮，也不能等同只是當前瞬間消滅 |
| **輪迴轉生** | 被摧毀後原地**滿血復活**；單體技能 | 需明確觸發條件、次數、復活是否保留舊狀態 |
| **直死打擊** | **死亡不可避免**；狀態技能 | 「必死」是否能被復活續接？死亡結果是否不可逆？待決 |
| **境界分割** | 「**我們之間是不可能的**」；狀態技能 | 隔絕雙向互動還是可單向攻擊？待決 |
| **十分之一傷定義系統** | 被命中後只受**10%**傷害 | 傷害結算層，不改物理撞擊本身 |
| **季傷定義系統** | 被命中後只受**25%**傷害 | 保留原文「季傷」；可註釋為四分之一傷 |
| **半傷定義系統** | 被命中後只受**50%**傷害 | 按原來順序記錄，可能是較低階的規則 |
| **無傷定義系統** | **100% 減傷** | 不等於阻止所有「非傷害事件」如封印或抹消 |
| **無論任何攻擊，只扣 1HP** | 每次傷害事件上限為 **1 HP** | 應對「多段命中」及傷害事件定義另訂規則 |
| **萬象修改** | 隨意更改**物理／數學規則**；會**提前告知隊友**讓己方有防備，藉此重創敵人 | 例：「1+1=3」「氫密度減半」「砍掉光譜」「讓 0 不存在」 |

**傷害百分比語義請嚴格寫清楚：**「十分之一傷」是**剩餘傷害 10%**；「無傷」是**減傷 100%，剩餘 0%**。這是舊設定的文字定義，不要誤解成「十分之一傷提供 10% 減傷」。

### 3.1 規則衝突不是小問題

例：直死（必死）+ 輪迴轉生（死後立刻復活），可能成為**永遠死亡／復活循環**；存在抹殺（從未存在）與備份回溯又會爭奪「誰能引用不存在的物件」。

**【提案】建立可審計的優先序／互動規則，而不是照名稱猜誰更神：**

1. 先檢查目標是否可被識別、存在及是否在作用域。
2. 決定境界是否容許兩者互動。
3. 處理規則改寫或禁止、時間／世界線衝突。
4. 決定是否進入傷害、死亡、復活事件。
5. 最後才結算 HP、護盾、裝甲與事件紀錄。
6. 若觸發循環，應有固定的失敗／中止／收束規則，不能讓遊戲死迴圈。

「高位必定贏低位」只是簡化候選；需要考慮科技成本、局部／全局作用域、同階互斥，以及**使用者仍能理解敗因**。

### 3.2 萬象修改必須有「世界更新」代價【提案】

**使用者原案的亮點**不是只會 1+1=3，而是**己方提前得到通知**，能先設計相容工程，讓敵軍因依賴舊宇宙規則而崩潰。可當成戰略級世界更新協定：

- 宣告作用域、規則替換內容、持續時間；
- 對己方發布警告（不代表絕對免疫）；安排行動或安全停機；
- 執行替換（不是把新舊互相矛盾的規則同時添加進古典數學）；
- 戰後恢復／回滾，或留下可被探勘的永久規則傷痕。
- 必須揭露副作用及成本，不能免費一鍵「我要贏」或任意改玩家勝利條件。

**四個原始示例的差異：**
- 「1+1=3」：觸及算術公理／運算定義；比改一項物理常數更根本，會影響工程計算語義。
- 「氫密度變一半」：要指定溫壓、組成、密度與質量／體積哪個定義被改，否則不確定會怎樣。
- 「砍掉光譜」：要指定是移除特定電磁頻段、讓某頻段不可傳播，還是移除觀測／物理模式。
- 「讓 0 不存在」：如果連數學中的零也移除，可能連符號系統與數學結構都失去定義；是神級魔法，不要裝成已證實物理。

## 4. 要塞炮應該與艦載炮切開尺度

**【使用者原意】**艦載三攻擊科技到「次元碎片軌道炮／次元切割炮／次元崩壞炸彈」級；其下還有**要塞炮**，希望強到能影響**多重宇宙**。使用者另外提出終極名稱：

# **存在抹殺炮**

**【可選七階要塞序列，AI 提案，不是使用者原有完整清單】**

| 階層 | 提案名稱 | 攻擊對象／戰略獨特性 |
|---:|---|---|
| F1 | 因果崩解炮 | 切斷特定事件的因果後續 |
| F2 | 真空相變炮 | 改寫局部真空態；物理學只有理論類比，沒有可建造武器 |
| F3 | 宇宙弦斷裂炮 | 利用假想宇宙弦／拓撲缺陷 |
| F4 | 膜界穿透炮 | 假設可跨高維膜／宇宙攻擊 |
| F5 | 宇宙共振炮 | 攻擊宇宙整體的穩定條件 |
| F6 | 世界線收束炮 | 讓多條可能分支收斂為有限結果 |
| F7 | **存在抹殺炮／多重宇宙級** | 指定存在概念作為打擊目標，而非發出更粗的光束 |

**【提案】存在抹殺炮與單體存在抹殺模組的分級：**模組按單一具體目標處理；要塞炮可透過宇宙級定位同一身份跨多世界線實例處理。**跨宇宙的互通機制目前不存在已證實物理**，要先確立是否有共有底層空間／真空／因果索引，否則「多重宇宙全抹消」只剩台詞。

有趣但可延後的更荒誕候選：**觀測終止炮、正史指定武器**。若把敘事層當成可直接改的世界規則，會有「所有正常遊戲技術失去作用」的平衡危機。請放在遠古神話／危險遺物，不在一般玩家戰術欄。

## 5. SCP 式現實穩定錨作為反制概念【靈感】

使用者聯想到 **Scranton Reality Anchor（SRA）**：現實扭曲可被局部穩定的概念。可借用其「偵測異常 → 比較基準 → 回饋校正」的**控制論形象**，原創化為：

| 反制【提案】 | 可限制的異常 |
|---|---|
| 空間錨／航道錨 | 閃現、傳送、空間注入 |
| 現實穩定裝置 | 局部物理規則異常 |
| 因果錨 | 回溯／因果打斷 |
| 存在錨定 | 在有限作用域中保護身份存續 |
| 多重宇宙基準錨 | 跨分支回復參照（只適合超古代劇情） |

**SCP 並無統一單一 canon；SRA 在不同條目解釋不同。** 不能說 SRA 對一切概念或敘事武器必勝。**著作權與原創：**此處是比較用名詞；正式本作需用自創設備名稱、世界規則、造型，不直接搬進 SCP 專有世界設定。

## 6. 魔法學派放大到星際戰爭的方向【內容庫】

| 魔法原型 | 科幻艦隊級「術式」提案 | 與普通強化火力的差異 |
|---|---|---|
| 分身／召喚 | 萬軍鏡界、萬界歸一 | 不只多出一個人，而是跨世界線調用整支艦隊 |
| 預言／命運 | 天機演算、命運收束 | 改變戰前情報與決策，而非炮傷 +500% |
| 幻術 | 天幕幻界、虛實逆轉 | 讓感測與星圖可信度崩潰；高階則幻象可實體化 |
| 時間魔法 | 時停聖域、千年一瞬、時間放逐 | 破壞交戰／補給時間尺度 |
| 結界／禁魔 | 星海禁行、境界分割、禁魔領域 | 限制互動與跳躍而不是厚盾 |
| 死靈／腐化 | 戰場感染、殘骸轉化、冥府投放 | 不單是幽靈船復活，詳見 [23](warfare-exotic-fleets.md) |
| 反魔法 | 大驅散、現實穩定錨、規則拒止 | 防止單一神級能力使戰鬥直接結束 |

**最重要的使用者修正**：宇宙級死靈術更接近《Homeworld: Cataclysm》的 **Beast 生物機械感染同化**——朝戰場投放能把艦隊／殘骸轉成自己資源的生態災害，**不是單純「死船站起來」**。

## 7. 與返鄉遊戲的玩法分隔

《Odysstra》的普通戰鬥仍以六系武器防禦、艦隊調動、補給與旗艦存活為主。神級模組／要塞炮可用於**前宗主國殘存遺產、禁區事件、歷史記錄、少量不可掌握威脅**。若未來允許玩家使用，必須先驗證不破壞「玩家自由返鄉」「旗艦沉即敗」「母星抵達即 Happy End」「戰勝國不可隨便被反制消失」等核心限制。

請不要把這份長清單誤寫成首版製作排程，也**不要硬把數學悖論寫成真實物理結論**。
