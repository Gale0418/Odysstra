# ODYSSTRA｜銀河歸途

> **The war is over. Bring them home.**  
> 戰爭結束了。帶他們回家。

**一支完整的遠征軍團、一份停止更新的軍用星圖，以及半個銀河的歸途。**

Odysstra 是以戰後返鄉為核心的 **2D 太空艦隊沙盒企劃**。第三次銀河大戰結束，科技高到難以想像的前宗主國遭到擊潰；原本只是宇宙級戰爭中一支微小附庸部隊的玩家，帶領仍保有作戰能力的同鄉軍團，穿過昔日友軍的領土、內戰、海盜與戰勝國逐步恢復的統治，返回共同的出生星球。

**目前狀態：設計文件建立階段，尚不代表任何遊戲功能已實作。** 本倉庫收錄 2026 年 11 月 14–15 日的設計討論與命名結果。文件會區分使用者已確認的方向、AI 提案、待決問題，以及已被後續修正的舊構想。

## 核心定位

| 項目 | 目前方向 |
|---|---|
| 玩家身分 | 戰敗陣營中仍有完整編制的作戰軍團；不是從一艘破船開始的難民隊伍 |
| 艦隊規模 | 標準幻想約 10 萬名同鄉、100 艘左右或百餘艘星艦；開局編組與後勤容量可以改變實際人數 |
| 目標 | 橫跨半個銀河，返回所有初始同鄉共同出生的母星；抵達即 Happy End |
| 玩法 | 自由航行、探索、戰鬥、維修、打撈、採礦、交易、搶劫與造船；可以回頭、停留、繞路或挑戰紅區 |
| 地圖 | 30 個有名字、有特色事件的地標；另有「70 種隨機組合但低價值的星系」方向。**70 的單位與每局總數尚未定義，不等於已定案 100 個星系** |
| 情報 | 前宗主國提供的超詳細軍圖停止更新；不是假地圖，也不是所有舊資料必然錯誤 |
| 對手 | 戰勝國依遊戲時間與戰略優先度接管各地；它能全圖監視艦隊，但仍要決定先處理誰 |
| 配船 | 可微調起始艦種；更高級的戰略資產帶來更高關注。泰坦是高風險候選，不是必選配備 |
| 後勤 | 食物以列印機與原料抽象處理；燃料能買，也能在恆星附近採集；不做逐餐種田管理 |
| 戰鬥 | **尚未正式定案**；候選是自動交戰搭配少量編隊級指令，避免逐艘微操百艦 |
| 人口 | 數字呈現；不模擬十萬個獨立角色，飛昇文明不以自然壽命作返鄉倒數 |
| 失敗 | 玩家所在旗艦被擊沉即 Game Over；換旗艦、撤退、存讀檔細則仍待設計 |

## 不要把遊戲做歪

- 不是單向 FTL 關卡，不以強迫道德抉擇取代航行與作戰。
- 不是每天為食物吵架的難民管理器；完整軍團不應被擅自改成全面殘血、連海盜都打不過。
- 不預設慘烈結局、不在母星加強制背叛或最終考試；返鄉成果由玩家實際遊玩決定。
- 不把戰勝國寫成沒有代價的全圖瞬移追兵，也不推翻它已被設定具有全圖艦隊監視能力。
- 普通星系可以真的普通；30 個地標也不等於 30 個全部必做的核武任務。
- 科幻彩蛋與遺產是候選內容，不是全部必須實作的功能承諾。

## 文件狀態標籤

`已確認` 表示使用者直接表達或明確更正的方向；`提案` 表示尚未採納的具體解法；`待決` 表示仍有缺口；`已取代` 表示不再適用的早期主張；`內容庫` 表示可挑選的素材，而非排程。

**閱讀優先序：最新使用者決定 → 決策紀錄 → 各系統文件 → 歷史會議／候選內容庫。** 不以其他 AI 的「這個定了」代替真正拍板。

## 名稱

**Odysstra** 是本次討論採用並建立倉庫的英文名稱，由 **Odyssey × Astra** 的融合造詞構想而來；中文專案名沿用《銀河歸途》。拼字固定為 `Odysstra`，標誌可使用 `ODYSSTRA`。

名稱含義、候選案與宣傳文案見[命名與調性](docs/12-naming-and-tone.md)。商標、商店與網域可用性未完成正式查核；此處不宣告獨占權。

## 開發現況

這次提交只建立設計基線，**沒有遊戲程式、可執行版本、完成的平衡數值或性能測試結果**。引擎、發行平台、授權方式與開發排程仍待決定。先用縮小戰區驗證航行、戰鬥、補給及接管壓力，再擴充正式內容。
